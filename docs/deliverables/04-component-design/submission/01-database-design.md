# 数据库设计说明

数据库设计覆盖学者、机构、成果、成果-学者关系、领域、认领申请、采集任务和审计日志八类核心对象，并配套 Elasticsearch 检索投影、分词与分面聚合、分类树和排行榜缓存。

正文依据 B 组成员 8 的数据库供稿，模型文件位于 `../models`，完整原始稿位于 `../source/route-b/member-08/component-design/data`。A 组成员 3 的 ER 候选和追踪矩阵保存在 `../source/route-a/member-03/component-design`，用于交叉复核。

成员 8 原稿明确标注为候选设计，数据库尚未连接或执行迁移；提交 Word 前必须由团队确认表结构、字段语义、索引、ES 映射和缓存策略，并将确认后的版本号写入封面和附录。
