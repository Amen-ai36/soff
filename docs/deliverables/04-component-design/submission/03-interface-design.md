# 接口设计说明

接口设计覆盖成果检索（过滤与分页）、学者门户查询、认领申请提交与审核、采集任务管理、统计查询，以及采集任务提交和进度查询的异步接口模式。统一约定 URL、HTTP 方法、分页、错误响应、幂等键、权限和版本字段。

候选 OpenAPI 文件为 `../models/openapi.json`，原始接口说明、验收映射和来源记录位于 `../source/route-b/member-08/component-design/api`。该 JSON 的结构可作为导入校验输入，但成员 8 原稿明确说明后端尚未运行，不能据此宣称接口已实现。

接口路径、请求/响应字段、错误码和业务状态须与数据库、UI 页面以及需求和架构阶段公共契约保持一致。若团队修改候选契约，应在整合记录中说明影响和迁移方式。
