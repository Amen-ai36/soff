# 构件设计唯一提交材料

本目录只保留一份统一提交材料。A、B 两组原始供稿在上级 `source` 目录中作为过程与复核材料，不另列第二份正式报告。

| 序号 | 课程要求 | 当前入口 | 说明 |
|---|---|---|---|
| 01 | 数据库设计说明书 | `01-database-design.md` | 内容统一稿；提交前转 Word |
| 02 | 数据库模型与 DDL | `../models` | 含 DDL、字典、元数据和 ES 映射 |
| 03 | E-R 图源文件与导出图 | `../models`、`source` | 已保留候选源与导出文件 |
| 04 | UI 设计说明书 | `02-ui-design.md` | 内容统一稿；提交前转 Word |
| 05 | UI 原型文件 | `../source/route-a/member-04-prototypes`、`../source/route-b/frontend` | 需选择并验证一个正式源 |
| 06 | 接口设计说明书 | `03-interface-design.md` | 内容统一稿；提交前转 Word |
| 07 | OpenAPI | `../models/openapi.json` | 候选 JSON，提交前导入校验 |
| 08 | 组内过程记录 | `05-integration-record.md` | 已记录路线差异，需补真实迭代事实 |

当前仓库统一材料是可追溯的 Markdown/模型源版本；课程若严格要求 Word 文档，提交负责人需在此目录生成对应 Word 文件后再提交。
