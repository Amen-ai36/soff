# UI 设计说明

统一 UI 设计覆盖成果检索页、学者门户页、成果详情页、认领申请页、管理后台采集任务管理页和认领审核页，并补充加载、空结果、失败、冲突、权限和窄屏状态。

A 组成员 4 提供信息架构、导航、视觉规范、交互状态以及可编辑 HTML 线框源。B 组成员 9 提供前端原型代码、14 张页面截图和检索、门户、认领、统计、管理页面 SPEC。两组内容都保留在 `../source`，正式实现只选择一套原型源，并以公共 API 和六类必需页面校验字段一致性。

截图是评审证据，不能替代可编辑原型源。现有供稿中的模拟数据、未完成真实用户测试和待确认接口依赖必须在最终说明书中如实披露。
