# 构件设计统一交付物

本目录是 A、B 两组构件设计供稿合并后的唯一阶段交付物。两组只提交这一套材料；A、B 的技术路线差异保存在 `source/route-a` 和 `source/route-b`，用于过程记录、复核和取舍说明，不作为两套并列终稿。

## 合并原则

- 数据库、接口、业务实体、状态和字段只保留一套公共语义。
- 采集与处理采用 A 组成员 2 的完整设计作为主要候选；B 组材料作为路线对照和复核依据。
- UI 同时保留 A 组可编辑 HTML 线框源和 B 组前端原型源，正式实现前选择一个版本，并以六类指定页面为验收基线。
- 任何候选材料中的“待共同确认”“未运行后端”“未完成真实用户测试”等状态必须保留，不能把设计稿写成已部署结果。
- 成员 5、10 在本阶段没有新的独立供稿，不重复制造第二套材料。
