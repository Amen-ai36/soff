# SPEC-M9-STATS-COLLAB-UI：统计分析与合作路径（创新候选）界面 v0.1

关联：SPEC-M8-STATS；03-innovation-integration.md；ADR-M9-04；契约假设 A-13。状态：候选规范。合作路径是否计为团队创新由成员 1、6 与老师确认。

## 1. 统计分析页

### 1.1 范围

五个区块，均来自统计服务，每块独立加载，一块失败不影响其他块（EX9-R-07）：

| 区块 | 服务端口径（SPEC-M8-STATS） | 界面必须显示 |
| --- | --- | --- |
| 成果类型分布 | 四类互斥，总和等于分母 | 每类数量与占比；分母 |
| 机构排名 | 多机构成果在每个机构各计 1；并列同名次后续跳号 | 名次、机构、数量；无机构数量单列；说明"各机构合计可能超过成果总数" |
| 领域分布 | 多领域可交叉，占比之和可大于 100% | 数量、占比；无领域数量；说明占比可交叉 |
| 领域热点 | 按年份，分母为当年成果数；给相邻年差量 | 年份、分母、各领域数量与占比、与上一年差量；年份未知数量 |
| 合作关系 | 共同成果去重计权；无自环 | 合作次数最多的前 10 对 |

### 1.2 显示规则

| 数据 | 规则 |
| --- | --- |
| `share = null` | 显示"无数据"（SPEC-M8-STATS 第 6 条：分母为 0 时不算 0/0） |
| `share` | 百分比保留 1 位小数 |
| 差量为 `null` | 显示"—（上一年无数据）"，不当作 0 |
| 差量 | 正数带"+" |
| 图形 | 条形只是装饰（`aria-hidden`），每行同时有文字数值（UI9-A11Y-06） |
| 口径 | 每块下方显示服务端返回的计数方式、分母、数据版本和更新时间 |

筛选：类型、年份区间，写入 URL，规则与检索相同（SPEC-M9-SEARCH-UI 第 3 节）。

## 2. 合作路径探索（创新候选）

### 2.1 开关

功能登记在 `features/registry.ts`。构建变量 `VITE_FEATURES`：未设置时启用全部登记功能；设为空字符串时全部关闭；否则为逗号分隔的功能 ID。关闭后路由不存在、导航与门户中的入口不显示，核心页面不受影响。页面标题旁显示"候选功能"。

### 2.2 算法（`domain/collabGraph.ts`）

| 编号 | 规则 |
| --- | --- |
| G1 | 无向图；节点为学者 ID；边来自统计服务返回的合作边 |
| G2 | 自环忽略；同一对学者出现多条边时合并，共同成果取并集，权重等于去重后的共同成果数 |
| G3 | 最短路径按边数最少，用广度优先搜索；权重不参与路径计算，只作为依据展示 |
| G4 | 遍历邻居时按学者 ID 的 Unicode 码点升序，结果确定 |
| G5 | 起点等于终点时路径只含该点；任一端不在图中或两端不连通时返回"无路径" |
| G6 | 度中心性 = 度数 ÷（节点数 − 1）；只有一个节点时为 0；按度数降序、ID 升序排列 |

### 2.3 页面

- 起点、终点从当前范围内的学者中选择，写入 URL（`from`、`to`）；可按领域、机构缩小范围（筛选在服务端执行）。
- 有路径时按顺序列出学者，每一步列出共同成果，可点开成果详情核对。
- 无路径时说明"在当前范围内两位学者没有合作关系链"。
- 页面写明：合作关系来自共同作者记录，作者消歧错误会导致路径错误；模拟模式下的路径没有学术含义。
- 门户中的"查看合作路径"把当前学者作为起点。
