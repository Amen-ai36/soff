# SPEC-M9-SEARCH-UI：检索与详情界面 v0.1

关联：UI9-FR-11～18；IA9-SEQ-01～04；IA9-RULE-01～09；FS9-L-*；EX9-C1、C2、C5、C6；SPEC-M8-SEARCH；契约假设 A-04、A-08、A-09、A-14。状态：成员 9 候选规范，待成员 4 对照、成员 8 汇编。

## 1. 目标与范围

| 在范围内 | 不在范围内 |
| --- | --- |
| 首页检索入口与领域入口 | 排序与匹配算法（SPEC-M8-SEARCH，服务端实现） |
| 成果检索结果页、成果详情页 | 联想词、检索历史（UI9-FR-19、20，P1，本版不做） |
| 学者检索结果页与同名提示 | 按题名/作者/期刊分字段检索：成员 8 接口中 `q` 只匹配题名、关键词、摘要，分字段检索需新增契约，待 ARCH9-Q03 一并确认 |
| URL 参数解析、校验、序列化 | 结果导出（UI9-FR-15，P1，本版不做） |

## 2. URL 参数

检索状态只存在于 URL（ADR-M9-03）。参数名为前端命名，与线上参数的转换在 `api/http.ts` 完成。

| URL 参数 | 含义 | 线上参数 | 默认值 | 是否写入 URL |
| --- | --- | --- | --- | --- |
| `q` | 关键词 | `q` | 空 | 非空时 |
| `type` | 成果类型，可重复 | `type` | 不限 | 有值时 |
| `from`、`to` | 年份区间 | `year_from`、`year_to` | 不限 | 有值时 |
| `field` | 领域 ID，可重复 | `field_ids` | 不限 | 有值时 |
| `inst` | 机构 ID，可重复 | `institution_ids` | 不限 | 有值时 |
| `sort` | `relevance`、`year_desc`、`year_asc` | `sort` | `relevance` | 非默认时 |
| `page` | 页码 | `page` | 1 | 非默认时 |
| `size` | 每页条数 | `page_size` | 20 | 非默认时 |

学者检索：`name`、`field`、`inst`、`page`、`size`；不接受 `sort`（SPEC-M8-SEARCH 第 6 条：学者不适用年份排序）。

## 3. 校验规则

URL 中任一参数不合法时页面进入"输入无效"状态：在对应字段显示原因，**不发请求**，不显示空结果（IA9-RULE-05、EX9-C2）。

| 字段 | 规则 | 错误文案 |
| --- | --- | --- |
| `q`、`name` | 去首尾空白后不超过 200 字符 | 关键词不能超过 200 个字符 |
| `type` | 只能是 `paper`、`patent`、`project`、`award` | 包含未知的成果类型 |
| `from`、`to` | 1000～9999 的整数 | 年份应为 1000 到 9999 之间的整数 |
| `from`、`to` | 两者都有时起始不晚于结束 | 起始年份不能晚于结束年份（错误挂在 `to`） |
| `sort` | 三个取值之一 | 不支持的排序方式 |
| `page` | 不小于 1 的整数 | 页码应为不小于 1 的整数 |
| `size` | 1～100 的整数 | 每页条数应为 1 到 100 之间的整数 |
| `field`、`inst` | 非空字符串；重复值去重 | — |

## 4. 修改条件的规则

| 编号 | 规则 | 来源 |
| --- | --- | --- |
| R1 | 除翻页外，任何条件变化后页码回到 1 | IA9-RULE-03 |
| R2 | 移除单个筛选保留关键词与其他筛选 | IA9-RULE-04 |
| R3 | "清除全部筛选"保留关键词与排序，清空类型、年份、领域、机构 | IA9-RULE-04 |
| R4 | 解析与序列化互逆：`parse(serialize(q))` 等于 `q` | ADR-M9-03 |
| R5 | 从详情页后退，恢复原条件与页码（由 R4 与浏览器历史共同保证） | IA9-RULE-06 |

## 5. 加载状态与反馈

| 状态 | 判定 | 界面 |
| --- | --- | --- |
| 加载中 | 请求进行中 | 保留页面框架；超过 300 ms 才显示"正在加载"（FS9-LR-01） |
| 有结果 | `total > 0` 且本页非空 | 结果列表、总数、当前排序、数据版本与更新时间 |
| 无匹配 | `total = 0` | "未找到匹配结果"；显示当前条件；提供"修改关键词"和逐个移除筛选；有筛选时提供"清除全部筛选" |
| 页码越界 | `total > 0` 且本页为空（成员 8 提案：越界页为空列表、总数不变） | "第 N 页没有结果（共 M 条）"与"回到第 1 页" |
| 数据已更新 | 仅翻页时 `data_version` 与上一页不同 | 在结果上方提示"翻页结果可能重复或遗漏"，提供"从第 1 页重新查看" |
| 失败 | 任何请求错误 | 按错误种类显示文案、追踪编号与重试；**不显示"0 条"** |
| 输入无效 | 第 3 节校验失败 | 字段级错误，不请求 |

无匹配时的恢复操作依据真实问卷 Q11（n=30）：换关键词 16 人、减少筛选 7 人、看平台建议 0 人。因此只提供上述两类直接操作，不做推荐。

筛选项名称（领域、机构）单独加载；加载失败只影响筛选面板，检索结果照常显示（EX9-R-07）。

## 6. 显示规则

| 数据 | 规则 |
| --- | --- |
| 结果卡片顺序 | 题名与年份为第一行；类型、作者、来源刊物为第二行；领域、机构为第三行；来源与模拟标记为末行（真实问卷 Q7：标题 23/30、年份 16/30，数据来源 0/30） |
| 作者 | 最多显示 3 位，其余写"等 N 人"；姓名为 `null` 时显示"未提供姓名" |
| `null` | 显示"未提供"；年份为 `null` 显示"年份未提供" |
| 空数组 | 显示"无" |
| `0` | 显示 0 |
| 模拟数据 | 列表与详情均显示"模拟数据"文字标记，不只靠颜色 |
| 原始链接 | `ok` 显示链接并注明在新窗口打开；`broken` 显示"原始链接已失效"且不生成链接；无链接或 `unknown` 显示"原始链接未提供" |
| 更新时间 | 详情页显示；超过阈值时提示"该记录可能不是最新"。阈值 30 天为候选值（IA9-Q02，待成员 2、7） |
| 学者卡片 | 依次显示研究领域、代表成果、机构（真实问卷 Q12：领域 18/30、代表成果 18/30、机构 11/30） |
| 同名提示 | 当前页有两位及以上姓名规范化后相同的学者时，在列表上方提示按领域、代表成果、机构区分 |
