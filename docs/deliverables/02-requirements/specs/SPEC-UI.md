## 2. 检索交互规格

### 2.1 搜索框行为

#### 2.1.1 输入状态

| 状态 | 触发条件 | 界面表现 | 后续动作 |
|------|---------|---------|---------|
| 空闲 | 初始状态 | 显示占位符："搜索成果、作者、机构..." | 点击聚焦 |
| 聚焦 | 用户点击或按 `/` | 边框高亮，占位符淡出 | 开始输入 |
| 输入中 | 字符数 > 0 | 显示清空按钮 (×) | 继续输入或提交 |
| 加载中 | 提交查询 | 搜索按钮显示加载图标 | 等待响应 |
| 已完成 | 结果返回 | 恢复默认状态，保留查询词 | 可修改或清空 |

#### 2.1.2 自动完成

**触发条件**：输入 ≥ 2 个字符，延迟 300ms

**建议列表结构**：
```
┌─────────────────────────────────┐
│ 🕐 机器学习                      │  (历史)
│ 🕐 深度学习算法                  │  (历史)
├─────────────────────────────────┤
│ 🔥 深度学习                      │  (热门)
│ 🔥 深度神经网络                  │  (热门)
└─────────────────────────────────┘
```

**交互行为**：
- `↓` / `↑`：选择建议项
- `Enter`：确认当前选择并执行查询
- `Esc`：关闭建议列表
- 点击建议项：执行查询
- 点击列表外：关闭列表

**验收标准**：
- 建议列表最多 8 条
- 历史优先于热门
- 请求失败不影响正常输入
- 移动端建议列表全屏显示

---

### 2.2 筛选器交互

#### 2.2.1 筛选器展开/折叠

**桌面端**：默认展开，可点击标题折叠

**移动端**：抽屉模式，点击"筛选"按钮展开

**折叠状态保存**：使用 localStorage，30 天有效

#### 2.2.2 多选筛选器（成果类型）

**交互流程**：
1. 点击复选框勾选/取消
2. 勾选后立即应用（无需点击"确定"按钮）
3. URL 同步更新：`?types=paper,patent`

**特殊规则**：
- 全不选 = 全选（不限制类型）
- 显示已选数量："成果类型 (2)"

#### 2.2.3 区间筛选器（年份）

**交互方式**：
- 方式 1：两个下拉框（起始年、结束年）
- 方式 2：双滑块（范围：1990～2024）

**快捷选项**：
```
[ ] 近 1 年   [ ] 近 3 年   [ ] 近 5 年   [ ] 近 10 年
```

**验证规则**：
- 起始年 ≤ 结束年
- 超出范围时显示警告："未找到该年份的成果"

#### 2.2.4 搜索式筛选器（机构、作者）

**交互流程**：
1. 在输入框输入关键词
2. 延迟 300ms 后请求自动完成
3. 点击建议项添加到已选标签
4. 点击标签的 × 删除

**已选标签样式**：
```
[清华大学 ×] [北京大学 ×]
```

**验收标准**：
- 最多选择 10 个机构/作者
- 标签可拖拽排序（P2）
- 移动端标签自动换行

#### 2.2.5 清除筛选

**位置**：筛选器面板顶部或底部

**行为**：
- 点击"清除全部"
- 所有筛选器恢复默认值
- URL 清除查询参数（保留 `q=`）
- 立即重新执行查询

---

### 2.3 排序交互

#### 2.3.1 排序选择器

**样式**：下拉框

**选项**：
- 相关度（默认）
- 时间降序（最新优先）
- 时间升序（最早优先）

**交互行为**：
1. 点击展开下拉列表
2. 选择选项
3. 立即重新请求结果
4. 滚动到页面顶部

**移动端**：使用原生 `<select>` 或全屏选择器

#### 2.3.2 排序状态指示

**位置**：结果总数右侧

**显示格式**：`按相关度排序 ▼`

**验收标准**：
- 当前排序方式高亮
- URL 同步：`?sort=date_desc`

---

### 2.4 分页交互

#### 2.4.1 页码导航

**样式**：
```
[首页] [上一页] [1] [2] [3] ... [10] [下一页] [末页]
```

**交互行为**：
- 当前页高亮且不可点击
- 点击页码跳转并滚动到页面顶部
- 第 1 页时禁用"首页""上一页"
- 最后一页时禁用"下一页""末页"

**省略规则**：
- 总页数 ≤ 7：显示所有页码
- 总页数 > 7：显示首页、末页和当前页附近 5 页

**移动端**：
```
[上一页] 第 2 / 10 页 [下一页]
```

#### 2.4.2 加载更多（移动端，P1）

**行为**：
- 滚动到底部触发"加载更多"按钮
- 点击后追加下一页结果
- 加载中显示 loading 图标
- 全部加载完显示："已显示全部结果"

**验收标准**：
- 每次加载 20 条
- 最多加载 200 条（10 页）
- 超过限制提示使用桌面端

**默认显示**：前 10 位作者

```
作者1, 作者2, 作者3, ..., 作者10 等 15 人  [展开全部作者 ▼]
```

```
作者1, 作者2, 作者3, ..., 作者25  [收起 ▲]

**默认显示**：前 500 字

```
[摘要前 500 字...]  [展开全部 ▼]
```

**点击展开后**：显示完整摘要，不提供收起按钮（假设用户展开后想阅读全部）

## 4. 认领流程交互规格

### 4.1 流程概览

**三步式流程**：
```
步骤 1      步骤 2      步骤 3
身份验证 →  成果选择 →  补充信息 → 提交审核
```

**进度指示**：
```
● ─────── ○ ─────── ○
1/3       2/3       3/3
```

**验收标准**：
- 当前步骤高亮（实心圆）
- 已完成步骤显示绿色
- 未到达步骤显示灰色
- 移动端进度指示固定在顶部

---

### 4.2 步骤 1：身份验证

#### 4.2.1 表单字段

| 字段 | 类型 | 必填 | 验证规则 | 错误提示 |
|------|------|------|---------|---------|
| 姓名 | 文本 | 是 | 2～50 字，中英文 | "请输入姓名" |
| 机构 | 下拉+搜索 | 是 | 从系统已有机构选择 | "请选择机构" |
| 邮箱 | 文本 | 是 | 邮箱格式，.edu.cn 或机构邮箱 | "请输入有效的教育邮箱" |
| 验证码 | 文本 | 是 | 4 位数字 | "验证码错误" |

#### 4.2.2 实时验证

**触发时机**：字段失焦（blur）

**验证流程**：
1. 客户端验证格式
2. 格式正确后异步验证唯一性（邮箱）
3. 显示验证结果图标：
   - ✓ 绿色：验证通过
   - ✗ 红色：验证失败
   - ⏳ 灰色：验证中

#### 4.2.3 机构搜索

**交互流程**：
1. 点击机构字段展开下拉列表
2. 显示常见机构（前 20 个）
3. 输入关键词搜索：延迟 300ms 请求
4. 显示匹配结果（最多 10 个）
5. 点击选择或按 Enter 确认

**未找到机构时**：
```
未找到"XXX"？  [手动输入]
```

点击"手动输入"切换为文本输入框（需管理员后续审核）

#### 4.2.4 查找候选门户

**提交验证**：点击"下一步"按钮

**加载状态**：
```
正在查找您的学者门户...  [loading 动画]
```

**结果处理**：
- **找到 1 个门户**：自动进入步骤 2
- **找到多个门户**：显示列表供选择
  ```
  找到 3 个可能的学者门户，请选择：
  ○ 张伟（清华大学，计算机科学）
  ○ 张伟（北京大学，电子工程）
  ○ 张伟（机构未知）
  ```
- **未找到门户**：提示创建新门户
  ```
  未找到匹配的学者门户
  
  我们将为您创建新的学者门户，请继续。
  [继续下一步]
  ```

---

### 4.3 步骤 2：成果选择

#### 4.3.1 候选成果列表

**列表结构**：
```
┌─────────────────────────────────────┐
│ ☑ 标题1                              │
│   作者 · 2023年 · OpenAlex           │
├─────────────────────────────────────┤
│ ☑ 标题2                              │
│   作者 · 2022年 · DBLP               │
├─────────────────────────────────────┤
│ ☐ 标题3                              │
│   作者 · 2021年 · 专利数据库          │
└─────────────────────────────────────┘

已选 2 条成果
```

**默认状态**：全选

**交互行为**：
- 点击复选框勾选/取消
- 点击标题展开详情（抽屉或模态框）
- 提供搜索框：按标题、年份筛选

**验收标准**：
- 最多显示 100 条候选成果
- 至少选择 1 条才能进入下一步
- 底部显示"已选 X 条成果"

#### 4.3.2 无候选成果

**提示内容**：
```
暂未找到您的成果

可能原因：
- 成果尚未被系统采集
- 作者姓名拼写不一致
- 成果已被其他用户认领

您可以：
[继续认领并手动添加成果]  [返回修改信息]
```

**点击"继续认领"**：跳过成果选择，直接进入步骤 3

---

### 4.4 步骤 3：补充信息

#### 4.4.1 表单字段（全部可选）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 个人主页 | URL | 否 | 个人网站或学术主页 |
| ORCID | 文本 | 否 | 格式：0000-0001-2345-6789 |
| 简介 | 多行文本 | 否 | ≤ 500 字 |

#### 4.4.2 ORCID 格式验证

**实时验证**：输入时检查格式

**格式**：`0000-0001-2345-6789`（4 组 4 位数字，连字符分隔）

**错误提示**：
```
ORCID 格式不正确
正确格式：0000-0001-2345-6789
```

#### 4.4.3 简介字数统计

**显示位置**：文本框右下角

**格式**：`125 / 500`

**超出限制时**：
- 字数变红色
- 提交按钮禁用
- 提示："简介不能超过 500 字"

#### 4.4.4 跳过补充信息

**位置**：步骤 3 底部

**文案**：`跳过，直接提交`

**行为**：跳过当前步骤，直接提交认领申请

---

**存储方式**：localStorage

```

**过期时间**：7 天

**排序选项**：
