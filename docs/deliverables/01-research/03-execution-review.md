# 统一执行与复核计划

适用第2～6教学周；具体日历日期以实际课表为准。下表为计划安排，未把任务分派、接受或会议记为已发生。

## 1. 十人供稿与协作

| 成员 | 主责交付 | 跨组协作与收件标准 |
| --- | --- | --- |
| 1 | 总体方案、范围、统一报告汇编、A组任务跟进 | 与6统一术语和结论，收齐各章及证据后汇编 |
| 6 | 总体方案、范围复核、B组任务跟进、正式报告复核 | 与1核对目标、范围和进度；给出逐项问题与复查结论 |
| 2 | A侧四类来源和获取可行性材料 | 与7共编一张来源调查表，保留各自样本/失败证据 |
| 7 | B侧来源和领域分类材料 | 与2比较分类和数据质量，3、8补充映射需求 |
| 3 | A侧竞品观察及科研人员/管理员流程 | 与8按相同维度形成一份对比和业务流程材料 |
| 8 | B侧竞品观察与角色诉求 | 与3核对认领、维护、检索和异常业务规则 |
| 4 | 访谈提纲、普通用户旅程及A侧调查 | 与9共编提纲，实际访谈记录独立匿名保存 |
| 9 | B侧调查、页面需求与交互观察 | 与4汇总场景及限制，禁止模拟记录冒充访谈 |
| 5 | A侧收件、证据索引、PPT共同制作 | 与10维护一个材料清单与PPT，不承担他人原始调研 |
| 10 | B侧收件、复核记录汇总、PPT共同制作 | 与5检查引用和报告/PPT一致性 |

## 2. 教学周里程碑

| 周次 | 计划成果 | 检查门槛 |
| --- | --- | --- |
| 第2周 | 总体方案、任务认领、问题清单、材料路径 | 两组目标一致；各项有负责人和期限 |
| 第3周 | 四类来源候选、竞品记录、访谈提纲、总体章节初稿 | 每项有来源和状态，无法访问也留下记录 |
| 第4周 | 调查材料、分类比较、范围修订、统一报告初稿 | 证据、假设、结论可区分；缺项有补交计划 |
| 第5周 | 成员6首轮复核、整改台账、唯一PPT初稿 | 问题定位到章节和责任人，报告/PPT数据一致 |
| 第6周 | 修订报告、PPT、附件、真实复核与评审反馈 | 可定位版本；未解决事项说明影响，不虚填通过 |

## 3. 收件与风险处理

每项提交正文、来源与证据位置、实际观察、推断、假设、局限和待决问题。无需为调研文案附AI提示词。数据材料必须覆盖四类成果及分类；竞品材料不能只有截图；用户材料区分提纲与真实记录。

数据不可用时，成员2、7提供备用来源与失败证据；用户不可接触时，成员4、9说明替代方法和样本限制；范围歧义由1、6汇总向老师确认；章节迟交由原作者提出补交时间；术语冲突由汇编人与复核人共同处理。

## 4. 正式报告复核门槛

成员6对被审版本逐项记录通过、有问题或不适用及证据，成员1组织整改。

1. 目标、对象、方法与实际执行相对应。
2. 三类角色诉求完整，四类成果来源均有材料。
3. 来源、许可、日期、访问失败与备用路线可追溯。
4. 分类候选、映射和质量/更新问题有依据。
5. 竞品观察、用户记录和推断不混淆。
6. 检索、认领审核、成果维护、采集更新流程含异常。
7. R01～R15有结论或明确未决说明，必做项未降级。
8. 基础分析和创新的边界清楚。
9. 报告、PPT、附件一致且正式版本唯一。
10. 隐私处理、引用、贡献和整改记录可追溯。
