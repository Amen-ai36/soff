## 关键边界

成员 9 供稿中声明的三条边界，汇编时需保持：

1. **前端状态 ≠ 业务状态**：前端可观察状态（加载中、已展开）由成员 4、9 定义；业务状态枚举（`PENDING`、`APPROVED`）由成员 3、8 定义。前端不覆盖、不推断业务状态。

2. **界面交互时序 ≠ 服务处理时序**：成员 4、9 的时序图描述界面与服务的交互契约层面，成员 3、8 的时序图描述服务内部处理，两者在"请求/响应"处衔接，不重叠。

3. **未定义公共契约**：成员 9 供稿不含 API 路径、字段名、错误码、状态枚举，相关处均标注为待对应岗位提供。
