# SPEC-M8-AUTH：认证与授权 v0.1

关联 M8-AUTH-01/02、M8-NFR-02；UC08-03～05。状态：需求提案；会话实现和密码策略待设计。

## 目标及边界

区分账户控制权、平台角色和门户所有权；不在本阶段选择 OAuth/JWT/服务端会话框架，不接入真实账号或新建管理员。

## 行为契约

登录输入凭据，成功建立有效会话，失败给通用提示；不在日志、错误、URL 中回显凭据。密码不得以明文存储，具体算法后续设计。退出使当前会话失效；过期、禁用、撤销权限均由服务端检查，不只依赖前端按钮。

| 操作 | 访客 | 普通登录用户 | 已认领学者 | 管理员 |
| --- | --- | --- | --- | --- |
| 公开检索/门户/统计 | 可 | 可 | 可 | 可 |
| 提交认领 | 否 | 可 | 可（其他可申请门户，数量策略待定） | 可但禁止自审 |
| 查询申请证据 | 否 | 本人 | 本人 | 职责范围 |
| 审核认领 | 否 | 否 | 否 | 可，排除本人申请 |
| 编辑个人门户允许字段 | 否 | 否 | 已授权门户 | 治理流程，不默认任意静默覆写 |
| 修改共享成果字段 | 否 | 否 | 提交变更建议 | 经治理权限与审计 |

所有写请求按“有效会话 → 操作权限 → 对象授权 → 参数/版本 → 写入”校验。客户端提供的 role、owner_id、applicant_id 不得用于提升权限。需 Cookie 方案时设计 CSRF 防护；令牌方案需撤销/有效性策略，不能通过退出仅删前端令牌声称服务端撤销。

## 异常与验收

未认证与已认证无权限区分；读取私有对象采用不泄露存在性的响应；服务失败不当作认证成功。AC08-07、08、12、21、25 验证过期会话、退出重放、自审、他人资源、伪造角色和材料引用。限速、有效期、锁定阈值、账号注册方式由公共设计确认，不能通过此草案默认授权开放注册或管理员自助注册。
