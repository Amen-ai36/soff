# 接口需求约束提案

本文件规定需要统一的业务语义，不是已批准 OpenAPI；未给出固定 URL、数据库字段或依赖版本。路径和字段命名在第 10～12 周构件设计时与成员 3、1、6 确认。

## 1. 公共数据语义建议

| 项目 | 建议约束 |
| --- | --- |
| ID | 不透明非空字符串；账号、学者、成果、机构、领域、申请各自有 ID；姓名不能作主键 |
| 成果类型 | paper/patent/project/award 四种；映射未知的原始数据进入治理，不假归类 |
| 时间 | 时间戳统一带时区，示例为 UTC ISO 8601；年份为整数或 null，不用 0/当前年替代缺失 |
| 缺失值 | null 表未知，[] 表无关联，0 表已知数量为零；公开显示“未提供”而非猜测 |
| 分页 | 建议页码从 1 开始，page_size 默认 20、范围 1～100；越界页为空列表，总数不变 |
| 过滤 | 不同维度 AND；同维度多选 OR；缺失字段仅在明确选择 unknown 时匹配 |
| 排序 | 固定数据版本内稳定；空年份排末；同分按稳定 ID；输入字段白名单 |
| 认证 | 会话机制待选型；任何方式均需到服务端检查有效性与资源授权；令牌不进 URL |
| 错误 | 机器码、可读消息、追踪 ID、可选字段错误；不得返回堆栈、材料正文或密钥 |
| 追溯 | 数据来源、处理批次、更新时点、模拟标记保留；公共展示与私有证据分离 |

## 2. 操作输入输出与权限

| 操作 | 输入 | 输出 | 权限/一致性 |
| --- | --- | --- | --- |
| 登录/退出 | 登录凭据；退出为当前会话 | 会话状态/失效结果 | 登录错误通用化；退出后旧会话不能继续写 |
| 成果检索 | q、type、year_from/to、institution_ids、field_ids、sort、page/page_size | items、total、page、page_size、data_version、updated_at | 仅公开数据；非白名单拒绝 |
| 学者检索 | name、institution_ids、field_ids、分页 | 学者 ID、公开姓名、机构、领域、分页信息 | 不返回账号、证明材料或私有联系方式 |
| 门户/详情 | 目标 ID、成果分页 | 公开基本信息、四类成果、来源和认领状态 | 按公开范围；状态不公开申请者身份 |
| 提交认领 | scholar_id、evidence_refs、request_key | application_id、status、version | 申请者由会话取得；材料引用必须属于本人且可核验 |
| 查询认领 | application_id | 状态、本人可见理由、时间 | 本人或授权管理员；对无权者不泄露存在性 |
| 审核 | application_id、decision、reason、expected_version、request_key | 最终状态及新版本 | 管理员且非申请者；通过与授权原子提交 |
| 成果维护 | 目标 ID、允许修改的字段、expected_version | 更新版本或变更申请编号、发布状态 | 只在授权范围；禁止客户端提升权限 |
| 统计 | 时间/类型/机构/领域过滤、分析类型 | groups/nodes/edges、口径、分母、版本、更新时间 | 公开范围与检索一致；基础关系仅公开成果 |

## 3. 错误分类与边界

下列为可选 HTTP 映射建议：参数错误 400；会话缺失/失效 401；操作无权 403；不可公开目标 404（含无权读取私有申请时）；并发、占用、幂等键参数不同 409；超限 429；依赖失败 503。机器码建议 INVALID_INPUT、UNAUTHENTICATED、FORBIDDEN、NOT_FOUND、CONFLICT、RATE_LIMITED、DEPENDENCY_UNAVAILABLE，冻结前不得当作已发布契约。

同一用户+同一操作+同一 request_key+相同参数重试返回已有结果；相同 key 不同参数冲突。幂等有效期建议 24 小时，团队可调整；超过有效期仍由待审核唯一约束、门户唯一所有者及终态不可改保证业务安全。

## 4. 状态、权限和数据同步

认领最小状态：PENDING、APPROVED、REJECTED。无效提交不创建申请；通过/驳回为当前申请终态；驳回重提创建新 ID。撤销、申诉、转让另议，不默认具有。门户所有者和待审核申请的并发约束见 SPEC-M8-CLAIM。

持久化成功才响应成功。通过时审批状态与授权必须同事务或等价原子保证。检索/统计可最终一致，但输出版本和更新时间；撤下或改为私有的记录应在公开响应阶段按权威可见性过滤，不能靠延迟索引继续暴露。索引失败返回可追踪待同步状态，不谎报已在所有视图发布。

## 5. 证明材料与接口示例边界

材料存储方案、类型/大小限制、保存周期与授权下载方式待确认；应拒绝不可访问和不属于申请者的引用。检索、门户、统计绝不嵌入证明正文。审计只记必要操作者、对象、动作、版本、结果和时间，不复制凭据和证明材料。

所有夹具中的用户和学者都是合成标识，不用于真实身份核验。本包没有发送真实申请或调用外部平台写入接口。
