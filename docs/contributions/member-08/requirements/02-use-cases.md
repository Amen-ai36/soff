# 用例说明（供全局用例图引用）

关联：SRS 的 M8-*；对应验收场景见 traceability.csv。所有编号都是本包局部编号。

## UC08-01 检索成果/学者

- 参与者：访客、登录用户；触发：提交搜索。
- 前置：公开数据可用；成功后置：结果满足过滤且分页/排序确定；失败后置：无数据写入。
- 主流程：选择对象 → 输入关键词/过滤 → 校验 → 匹配 → 排序 → 分页 → 显示总数与条件 → 查看详情/门户。
- 备选：空关键词作公开列表；无匹配返回 total=0；同名学者保留不同 ID。
- 异常：错误类型/年份/页码拒绝；索引不可用返回依赖失败；翻页时版本失效提示重新查询。

## UC08-02 浏览门户与详情

- 参与者：访客；前置：目标是可公开记录。
- 主流程：通过 ID 定位 → 读取公开信息 → 按四类成果组织列表 → 查看来源、时间、机构、领域与认领入口。
- 后置：不改变归属；私密证据不出现在响应。
- 异常：不存在或无权公开的记录使用不暴露细节的“不可访问”；暂无成果显示空列表，缺失领域显示“未提供”。

## UC08-03 提交认领

- 参与者：登录用户；前置：有效会话、目标门户存在且可申请。
- 主流程：选择门户 → 提交材料引用 → 系统校验可读材料、重复和占用 → 创建 PENDING 申请 → 返回申请编号 → 本人查状态。
- 后置：仅形成申请，不授予门户维护权。
- 异常：不完整返回字段错误；已有本人 PENDING 返回现有申请/冲突；已占用返回冲突；重试同一幂等请求不新建申请。
- 备选：REJECTED 申请不可覆写，修正后创建新申请并关联前序编号。

## UC08-04 审核认领

- 参与者：管理员；前置：待审核申请，审核者不是申请者。
- 主流程：查看材料及上下文 → 依据既定证据标准核验 → 通过或驳回 → 原子校验版本与占用 → 保存审核原因、审计记录及通过时授权关系 → 本人查结果。
- 后置：APPROVED 与授权同时成立；REJECTED 无授权且有理由。
- 异常：并发已处理/他人抢先认领返回冲突；写入失败整笔回滚；材料不足走有理由驳回；通知失败不改变已提交结论，状态查询仍是权威入口。

## UC08-05 维护成果

- 参与者：已认领学者；前置：服务端核验当前授权与记录版本。
- 主流程：读取当前值 → 提交个人字段补充/成果补录/关联纠错 → 校验 → 允许范围直接保存或形成待审变更 → 留痕 → 告知保存与公开更新状态。
- 后置：共享成果不被无授权删除；重复导入保留来源不重复增量计数。
- 异常：他人门户拒绝、过期版本冲突、缺必填拒绝；公共字段冲突交治理；外部采集与人工值冲突不静默覆盖。

## UC08-06 查看统计、关系与热点

- 参与者：访客、科研人员、管理员；前置：存在可读统计数据集或明确的空数据状态。
- 主流程：设置范围 → 校验 → 固定快照 → 去重聚合 → 展示计数、口径和更新时间 → 可追溯到支撑成果。
- 备选：空集合类型计数为 0、比例为 null，界面显示“无数据”；未知年份放未知组，无年份趋势不强行补到当年。
- 异常：数据库/统计服务失败返回可识别错误；不将缺失值当真实零值；无证据关系不生成边。

## 用例关系建议

检索后查看详情/门户是可选后续行为，不强行建成 include。提交认领和维护都要求认证前置；审核要求管理员身份，不能通过“已登录”替代。成员 1、6 将以上参与者及用例加入同一张系统用例图，同时保留成员 2、7 的采集管理用例。
