# 后端架构与选型比较：B组候选

2026-11-11，版本0.1。关联M8-AUTH、SEARCH、PORTAL、CLAIM、MAINT、STAT需求，承接统一分析AN-Q04～09。图中的服务是逻辑职责，部署进程数量尚未冻结。

## 1 分层与模块

建议以有明确模块边界的业务应用配合独立异步工作进程作为一期B方案。七类逻辑服务全部保留，认证、认领等需共同提交的操作先避免拆成跨库事务。架构图见 `diagrams/backend-architecture.puml`。

| 层/模块 | 职责与主要输入输出 | 边界 |
| --- | --- | --- |
| 采集服务 | 任务提交、来源访问、进度、停止与失败记录 | 成员2/7负责，任务状态差异待共同映射 |
| ETL服务 | 清洗、去重、作者消歧、来源与规范成果映射 | 不静默覆盖人工修正；输出候选版本 |
| 检索服务 | 已发布公开版本上的过滤、排序、分页和合法total | 不自行把同名合并；不改既有加权排序为BM25 |
| 门户与认领服务 | 四类成果展示、申请、审核、唯一授权、维护与治理 | 账号≠学者；待审不授权；公共成果不归展示关联所有 |
| 统计服务 | 同版本去重计数、机构/领域分布、合作边与年度热点 | 公开集合与检索相同；披露分母、未知数 |
| 认证服务 | 会话、退出、当前角色与资源权限 | 服务端验证；管理员不得自审；Cookie+CSRF仅候选 |
| 管理后台服务 | 任务管理、受控证明查看、审核与发布运维入口 | 后台页面不直接连接数据库、ES或证明桶 |
| 同步/发布工作进程 | Outbox重试、索引构建、逐项确认、集合对账与发布 | 不拥有业务真相，不从消息次数推断成果数量 |

## 2 三种架构路径比较

| 候选 | 优点 | 代价/本阶段判断 |
| --- | --- | --- |
| 单进程混合所有逻辑 | 初始部署简单 | 采集阻塞可拖累查询，职责不清；不作为B优先方案 |
| 模块化业务应用+异步工作进程 | 可使用本地事务保护审核；工作负载可独立扩容；维护成本较低 | 仍需模块访问约束；业务进程故障会影响多个服务；B推荐候选 |
| 七类逻辑服务分别部署为微服务 | 可独立发布与扩缩容 | 身份、幂等、分布式一致性与运维成本增加；暂无实测依据证明课程阶段收益 |

以上是基于项目约束的设计判断，不是A组已选方案或性能比较结论。成员3提供A方案后，按相同数据量、故障场景和部署预算对照。

## 3 存储与公开投影

关系数据库候选PostgreSQL保存规范实体、来源关系、申请、授权、审核决定、审计、任务和Outbox，作为权威业务状态。其事务内行锁可控制并发更新；本方案进一步结合版本条件和唯一约束保护审批，[官方锁说明](https://www.postgresql.org/docs/current/explicit-locking.html)不替代本项目事务验证。

ES仅存白名单公开投影和排序/聚合字段，不能存认领证明、会话凭据或私有联系方式。Redis为可选缓存，不作权限和审批真相；分类树可版本缓存，排行榜键绑定已发布版本及过滤条件，命中后仍需公开栅栏校验。缓存失效或故障可跳过缓存，权威权限服务故障则关闭受保护读写。

私有证明存储候选OBS私有桶，数据库保存受控对象引用；证明下载经当前身份和职责校验后由后端代理提供。OBS默认资源私有且有多种授权机制，[官方权限说明](https://support.huaweicloud.com/intl/en-us/perms-cfg-obs/obs_40_0001.html)。短时签名URL可作为另议优化，但URL持有者在有效期内可能转发；它不等同于每次重新校验申请权限，不能混入公开缓存或日志。[临时URL说明](https://support.huaweicloud.com/intl/en-us/perms-cfg-obs/obs_40_0009.html)

## 4 部署与容量工作项

候选一期部署使用ECS承载业务应用及独立工作进程，RDS PostgreSQL保存权威状态、CSS承载ES公开投影、私有OBS保存证明。逻辑服务不要求各建一个ECS。CCE、具体实例规格、备份保留、IAM角色、网络与地域由成员5/10和1/6确认，图 `deployment-boundary.puml` 只是拟议边界。

按至少1,000,000条规范公开成果规划：按ID唯一计数、批处理有界分页、可重建索引、检查发布积压和恢复时间；原始来源、隔离数据和重复作者均不充当目标成果数。分片数、磁盘、P95和费用需基于实际文档大小、分布、并发、查询复杂度测量后确定，不给无依据规格。华为云CSS候选版本是否支持本稿引用的Elastic API，必须在选型时实测兼容性。
