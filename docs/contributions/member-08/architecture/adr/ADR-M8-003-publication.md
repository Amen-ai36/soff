# ADR-M8-003：公开索引代、策略栅栏与可解释分页

状态：Proposed；2026-11-11。关联AN-Q07/08、M8-SEARCH及STAT。

背景：旧索引或PIT可能仍含已撤下记录；只过滤当前页无法保证total和聚合合法。百万级深分页也不能无条件沿用大偏移查询。

候选决策：使用数据库公开epoch/READY栅栏和不可变具体索引代；收缩公开资格时同事务阻断旧代的新响应授权，新代完整集合对账通过后再发布。查询上下文绑定代、条件、排序和epoch，每次翻页重验；数据稳定由PIT等提供，权限仍由当前权威栅栏控制。

依据与推导：Elastic支持PIT/search_after稳定遍历，别名支持多动作切换；数据库与ES仍无天然共同提交。全局栅栏与阻断策略是本项目为正确性提出的保守方案，[分页](https://www.elastic.co/docs/reference/elasticsearch/rest-apis/paginate-search-results)、[别名](https://www.elastic.co/docs/manage-data/data-store/aliases)。

替代：逐页删除受限项会泄漏总数，拒绝；完整权限集合下推可降低全局阻断，但实现和验证成本更高，作为后续替代评审。

后果：count、统计、缓存与当前公开策略有一致依据；收缩期间公开查询可用性下降。深页建议游标/快照，既有页码兼容范围须共同批准，不能单方更换加权排序为BM25。

接受条件：评审阻断可用性代价，验证最终授权与撤下并发、旧PIT/旧缓存、发布竞争、精确total及集合对账。尚无上线、性能或安全通过结论。
