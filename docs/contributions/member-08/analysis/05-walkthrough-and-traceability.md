# 10 模型场景走查与后续验证

| 走查场景 | 模型应保持的结果 | 定位 |
| --- | --- | --- |
| 重复来源 / 多作者 | 同一规范成果不多计；规范关系去重；来源证据可增加。 | CLS-01；SEQ-05；AC08-24 |
| q=graph固定样例 | 顺序W01,W02,W03；total=3；非公开W05排除。 | SEQ-01；AC08-01/03 |
| 同键重试/变更参数 | 同参数同ID；异参数冲突；不新增重复待审。 | SEQ-02；AC08-09 |
| 两申请争同门户 | 最多一有效授权；落败申请不自动驳回。 | SEQ-03；AC08-12 |
| 同申请并发 / 审核写入失败 | 不覆盖已成功终态；本次失败无部分决定、授权或审计。 | SEQ-03；AC08-10/13 |
| 网络回包丢失 / 通知失败 | 查询或同键重试恢复结果；决定保持；通知独立追踪。 | SEQ-02/03 |
| 已驳回补材料 | 新申请ID关联旧记录；旧终态不回退。 | CLS-02；AC08-11 |
| 隐藏展示 / 公共纠错 | 不全局删成果；共享字段进入治理请求。 | SEQ-04；AC08-22/23 |
| 过期公开快照 | 不能泄露已撤下内容或错误total；不能核验则失败。 | SEQ-01/05 |
| 真实空集 / 统计故障 | 空集成功计数0、比例null；故障明确错误，不假全零。 | SEQ-05；AC08-16/19 |

走查属于规则推演。后续成员5/10须在实际系统上覆盖会话失效、自审、他人材料、幂等重放、并发审核、失败回滚、版本切换和统计对账；再执行统一规模及性能验收。本轮没有业务代码、真实账号、真实采集或接口测试。

需求映射沿用成员8原追踪表全部18条需求、全部26个AC编号；不把分析页数、图数、夹具数或文档检查通过当作业务通过率。详细映射见traceability.csv。
