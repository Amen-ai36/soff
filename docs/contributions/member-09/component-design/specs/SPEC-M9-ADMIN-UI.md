# SPEC-M9-ADMIN-UI：管理后台界面（认领审核、采集任务）v0.1

关联：成员 6 稿第 3 节"管理后台 HTTPS 调用受控业务接口，不直接访问存储"；SPEC-M8-CLAIM 第 3～6 条；成员 7 采集任务候选状态 `collection-transitions.json` v0.1；契约假设 A-11、A-15、A-16。状态：候选规范。

## 1. 目标与范围

| 在范围内 | 不在范围内 |
| --- | --- |
| 认领申请列表与审核决定 | 审核证据标准（待成员 1、6 与老师） |
| 采集任务列表、创建、停止、重试 | 数据源审批、限速、调度策略（成员 2、7） |
| | 数据治理、发布状态（待成员 2、7、3、8 提供接口） |

页面不做角色拦截：非管理员进入后照常请求，由服务端返回 403，页面显示"无访问权限"。

## 2. 认领审核

### 2.1 列表

默认显示"审核中"，可切换"全部"。每条显示：申请编号、学者（链接到门户）、申请人、提交时间、关系说明、证明材料引用、状态、版本号。证明材料仅在本页显示，不进入公开页面。

### 2.2 决定

| 规则 | 内容 | 来源 |
| --- | --- | --- |
| A1 | 决定只能是"通过"或"驳回" | SPEC-M8-CLAIM |
| A2 | 驳回理由必填；通过理由可空 | SPEC-M8-CLAIM 第 3 条 |
| A3 | 提交前显示确认文字；通过时写明"申请人将获得该门户的维护权限" | — |
| A4 | 请求携带 `expected_version` 与 `request_key` | 成员 8 提案第 2 节 |
| A5 | 申请人是当前管理员本人时，按钮不可用并说明"不能审核本人提交的申请"；服务端仍须拒绝 | SPEC-M8-AUTH |
| A6 | 409 时提示"记录已被更新，已载入最新状态，请重新判断"，刷新列表，不自动重试 | FS9-BR-04 |
| A7 | 成功后以服务端返回的状态刷新，不在前端推断 | FS9-BR-02 |

## 3. 采集任务

状态和可用操作按成员 7 候选状态机，未冻结，页面标注"候选状态"。

| 状态 | 文字 | 停止 | 重试 | 依据（成员 7 转换） |
| --- | --- | --- | --- | --- |
| `PENDING` | 待执行 | 可 | 否 | T02 |
| `RUNNING` | 运行中 | 可 | 否 | T07 |
| `RETRY_WAIT` | 重试等待 | 可 | 否 | T11 |
| `STOPPING` | 安全停止中 | 否 | 否 | — |
| `FAILED` | 失败 | 否 | 可 | T12 |
| `SUCCEEDED` | 成功 | 否 | 否 | — |
| `STOPPED` | 已停止 | 否 | 否 | — |

- 已获取记录数为 `null` 时显示"未提供"，不显示 0。
- 操作返回 409 时提示"任务状态已变化"并刷新。
- 创建任务只能从服务端返回的获准数据源列表中选择。
