## 关键边界声明

三条边界贯穿本目录，避免越界定义其他岗位的内容：

1. **前端状态 ≠ 业务状态**：本目录定义前端可观察状态（加载中、已展开），业务状态枚举（`PENDING`、`APPROVED`）由成员 3、8 定义。前端不覆盖、不推断业务状态。

2. **界面交互 ≠ 服务处理**：本目录的时序图描述界面与服务的交互契约层面（用户看到什么、何时看到），服务内部处理时序由成员 3、8、2、7 定义，两者在"请求/响应"处衔接。

3. **不定义公共契约**：本目录不定义 API 路径、字段名、错误码、状态枚举。相关处均标注为待对应岗位提供。
