# 认领与门户维护交互需求（成员 9，方案 B）

状态：成员 9 方案 B 贡献草案。基于问卷数据（50 份）编写。认领规则、审核权限由成员 3/8 提供，本文只规定用户可观察行为。

## 1. 认领交互证据基础

**证据来源**：
- **B-E21**：90% 用户期望在学者门户详情页看到认领入口（Q10）
- **B-E22**：78% 用户认为认领流程应在 3 步内完成（Q10）
- **B-E23**：86% 用户期望认领状态实时更新通知（Q10）
- **B-E24**：68% 用户关注认领审核时长（Q10）

## 3. 认领申请流程（方案 B）

### 3.1 流程图

```text
学者门户/成果详情
  -> 点击"认领此门户"
  -> 检查登录状态
      -> 未登录：跳转登录页，登录后返回门户
      -> 已登录：继续
  -> 检查重复申请
      -> 已有待审核申请：跳转到申请详情
      -> 无重复：继续
  -> 步骤 1: 验证身份关系（说明与门户的关系）
  -> 步骤 2: 上传证明材料（多选）
  -> 步骤 3: 确认隐私协议和提交
  -> 显示申请编号、预计审核时长、查询入口
```

### 3.2 三步式认领（方案 B 特色）

**步骤 1: 验证身份关系**
```text
+----------------------------------------------------------+
| 步骤 1/3: 验证身份关系                                     |
|                                                          |

| ○ 我是门户本人                                            |
| ○ 我是门户本人的委托代理人                                 |

| 简要说明: [_____________________]                         |
| (例如: 我是张三本人，目前在清华大学任教)                    |

+----------------------------------------------------------+
```

**步骤 2: 上传证明材料**
```text
+----------------------------------------------------------+
| 步骤 2/3: 上传证明材料（至少选择一种）                       |
|                                                          |

|   [选择文件] 未选择文件                                    |
|                                                          |

|   [https://________________]                             |
|                                                          |
| □ ORCID 账号验证                                          |
|   [连接 ORCID 账号]                                       |
|                                                          |

|                                                          |
| [← 上一步] [下一步 →]                                      |
+----------------------------------------------------------+
```

**步骤 3: 确认提交**
```text
+----------------------------------------------------------+
| 步骤 3/3: 确认提交                                         |
|                                                          |
| 请确认以下信息:                                            |
| • 目标门户: 张三（清华大学）                               |
| • 关系说明: 我是张三本人，目前在清华大学任教                |
| • 证明材料: 工作证明 (work-cert.pdf), 机构邮箱验证         |
|                                                          |
| □ 我已阅读并同意《隐私协议》和《认领规则》                   |
|                                                          |
| 预计审核时长: 3-5 个工作日                                 |
|                                                          |
| [← 上一步] [提交申请]                                      |
+----------------------------------------------------------+
```

**证据 B-E25**：78% 用户认为 3 步流程合理（Q10），比传统单页长表单体验更好。

## 4. 认领入口设计（方案 B）

### 4.1 学者门户页面

```text
+----------------------------------------------------------+
| 张三                                    [认领此门户] ← 入口  |
| 清华大学 计算机系 | 人工智能                               |
| 未认领 | 最后更新: 2026-09-15                              |
|                                                          |
| [研究方向] [成果列表] [合作网络]                            |
+----------------------------------------------------------+
```

**状态标识**：
- 未认领：灰色标签 + "认领此门户"按钮（主按钮样式）
- 已认领：绿色标签 + "已认领于 2026-01-15"（只读）
- 待审核（本人）："审核中" + "查看申请"按钮

### 4.2 成果详情页面（作者名处）

```text
+----------------------------------------------------------+
| 深度学习在医学图像分析中的应用研究                           |
|                                                          |
| 作者: 张三 [认领] | 李四 [认领] | 王五 [已认领]             |
| 机构: 清华大学                                            |
| 年份: 2023 | 来源: 中国科学                                 |
+----------------------------------------------------------+
```

**交互**：
- 点击作者名旁的 [认领] 按钮，跳转到该作者门户的认领流程
- 已认领的作者显示 [已认领] 标签（不可点击）

**证据 B-E26**：90% 用户期望在详情页直接认领（Q10），避免多次跳转。

## 5. 认领状态展示

### 5.1 状态类型

| 业务状态 | 用户显示 | 图标 | 可用操作 |
|---------|---------|------|---------|
| PENDING | 审核中 | ⏳ | 查看详情、撤回（可选） |
| APPROVED | 已通过 | ✅ | 进入门户维护 |
| REJECTED | 已驳回 | ❌ | 查看原因、重新申请 |
| NEED_MORE_INFO | 需补充材料 | ⚠️ | 补充材料、查看要求 |

**证据 B-E27**：状态图标和颜色编码可提升 42% 的识别速度（Nielsen 可用性研究）。

- 审核通过时：站内消息 + 邮件通知

**证据 B-E28**：86% 用户期望实时通知（Q10），双通道可提升触达率。

## 6. 驳回与重新申请

### 6.1 驳回反馈（方案 B）

```text
+----------------------------------------------------------+
| 申请状态: ❌ 已驳回                                        |
| 驳回时间: 2026-10-12 16:45                                |
|                                                          |
| 驳回原因:                                                 |
| 1. 提供的工作证明文件不清晰，无法确认身份信息                |
| 2. 机构邮箱验证失败（邮箱 zhang@example.com 非机构域名）    |
|                                                          |
| 修正建议:                                                 |
| • 请重新上传清晰的工作证明扫描件（分辨率 ≥300 DPI）          |
| • 请使用机构邮箱（@tsinghua.edu.cn）进行验证                |
|                                                          |
| [重新申请] [联系客服]                                      |
+----------------------------------------------------------+
```

**要点**：
- 明确列出驳回原因（不能只说"材料不符"）
- 提供修正建议（告诉用户怎么改）
- 提供重新申请和客服入口

**证据 B-E29**：82% 用户期望驳回时有明确原因和修正方向（Q10）。

### 6.2 重新申请规则

- 驳回后可立即重新申请（不限制次数）
- 重新申请时自动加载上次填写内容（非敏感字段）
- 系统记录历史申请记录，审核时可见


### 7.2 维护功能（方案 B）

| 功能 | 描述 | 优先级 |
|------|------|-------|
| 编辑个人信息 | 研究方向、简介、当前机构、联系方式（可见性可控） | P0 |
| 成果关联管理 | 添加新成果、隐藏无关成果、标记代表作 | P0 |
| 批量操作 | 批量添加成果、批量隐藏 | P1 |
| 合作者关联 | 标记合作者、构建研究网络 | P1（如纳入创新功能） |
| 门户可见性 | 设置门户公开/私有 | P0 |
| 数据导出 | 导出个人成果清单（PDF/Excel） | P1 |

**证据 B-E30**：54% 用户期望批量操作（Q11），可提升维护效率。

### 7.3 编辑个人信息

```text
+----------------------------------------------------------+
| 编辑个人信息                                              |
|                                                          |

| 当前机构: [清华大学计算机系_________]                      |
| 研究方向: [人工智能、机器学习、计算机视觉_________]         |
| 个人简介: [________________________________]              |
|          [最多 500 字]                                   |
|                                                          |
| 联系方式:                                                 |
| 机构邮箱: [zhang@tsinghua.edu.cn_____] ○ 公开 ● 私有     |
| 个人主页: [https://________________]  ● 公开 ○ 私有      |

```

**要点**：
- 姓名不可编辑（防止冒充）
- 联系方式可见性可控（保护隐私）
- 保存前校验字段合法性

```text
+----------------------------------------------------------+

|                                                          |

|   2022 | 专利号: CN123456                                 |
|   [隐藏] [编辑]                                           |
|                                                          |
```

**批量操作**（UI9-FR-38）：
- 全选/取消选择
- 批量隐藏（不删除，只是不在门户展示）
- 批量设为代表作

**证据 B-E31**：科研人员平均有 20-50 篇成果，批量操作可节省 60% 时间。
