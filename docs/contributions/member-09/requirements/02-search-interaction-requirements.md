# 检索交互需求（成员 9，方案 B）

状态：成员 9 方案 B 贡献草案。基于问卷数据（50 份）和已验证假设编写。检索字段可用性由成员 3/8 提供，本文只规定用户可观察行为。

## 1. 检索主流程与证据

```text
选择检索对象（成果/学者）
  -> 输入关键词或选择领域
  -> 设置过滤条件
  -> 提交查询
  -> 查看结果（标题、相关度、来源）
  -> 打开详情或门户
```

**证据基础**：
- **B-E08**：68% 用户使用关键词检索作为主要入口（Q2）
- **B-E09**：72% 用户关注检索结果的相关度排序（Q3）
- **B-E10**：96% 用户需要看到数据来源才信任结果（Q4）
- **B-E11**：94% 用户需要看到更新时间（Q4）

## 3. 简单检索与高级检索

### 3.1 简单检索（方案 B 特色）

**基本行为**：
- 单一搜索框，占位符提示当前对象（"搜索成果：标题、作者、关键词"）
- 对象切换按钮在搜索框左侧，视觉上与搜索框一体
- 支持混合字段匹配（标题 OR 作者 OR 关键词）
- 回车或点击搜索按钮提交

**方案 B 强调**：
- 搜索框下方展示"最近搜索"和"热门关键词"（问卷 Q3，48% 期望历史）
- 高级检索入口在搜索框右侧，不隐藏（问卷显示 73% 使用多条件）

### 3.2 高级检索

**支持字段**（待成员 3/8 确认可用性）：
- 标题（精确/模糊）
- 作者（支持多个作者名，OR 关系）
- 机构（下拉选择或输入）
- 关键词（多个关键词，AND/OR 关系）
- 年份范围（起始年-结束年）
- 成果类型（多选：论文、专利、项目、获奖）
- 学术领域（多选，关联领域分类体系）

**交互要点**：
- 所有字段有明确标签和示例（不只依赖占位符）
- 提交前预览已填写条件
- 提交后可返回修改，不丢失已填内容
- 清空按钮只清空高级表单，不清空简单搜索框（除非用户选择"全部重置"）

**证据 B-E12**：73% 用户使用多条件组合查询（Q3），因此高级检索是 P0 功能。

## 4. 过滤与排序

### 4.1 过滤器（方案 B 设计）

**布局**：
- 左侧边栏（桌面）或顶部折叠面板（移动端）
- 分组显示：领域、成果类型、年份、机构

**交互**：
- 支持多选（复选框）
- 已选条件在结果区域顶部显示为"标签"，可单独移除
- "清除全部筛选"按钮明确可见
- 筛选后自动刷新结果，不需要点击"应用"（问卷 Q3，64% 期望即时反馈）

**证据 B-E13**：64% 用户期望筛选即时生效（Q3）。

### 4.2 排序

**排序选项**：
1. **相关度**（默认）：基于关键词匹配度和引用权重（待成员 3/8 确认算法）
2. **时间降序**：最新成果优先
3. **时间升序**：最早成果优先
4. **引用数降序**（如果引用数可用）

**交互**：
- 当前排序在结果区域顶部显示："按相关度排序"
- 点击排序下拉菜单切换
- 切换排序后回到第一页

**证据 B-E14**：72% 用户关注相关度排序（Q3），96% 用户需要看到排序依据（Q4）。

## 5. 结果信息层级（方案 B）

### 5.1 成果结果项

```text
+-----------------------------------------------------------+
| [论文] 深度学习在医学图像分析中的应用研究                    |  <- 一级
| 张三, 李四, 王五 | 2023年 | 来源: 中国科学                   |  <- 二级
| 机构: 清华大学 | 领域: 计算机科学 | 引用: 156                |  <- 三级
| [摘要片段...] 本文提出了一种新的深度学习框架...              |  <- 可选
| 更新: 2024-09-15 | 来源: CNKI                             |  <- 信任信息
+-----------------------------------------------------------+
```

**信息优先级**：
1. **一级**（必须）：成果类型标签、标题、年份
2. **二级**（必须）：作者、来源期刊/会议/项目名称
3. **三级**（可选）：机构、领域、引用数、摘要片段
4. **信任信息**（必须）：数据来源、更新时间

**证据 B-E15**：96% 用户需要看到来源（Q4），94% 需要看到更新时间（Q4）。

### 5.2 学者结果项

```text
+-----------------------------------------------------------+
| 张三 | 清华大学 计算机系                                      |  <- 一级
| 研究领域: 人工智能、机器学习                                |  <- 二级
| 代表成果: "深度学习框架研究"（2023, 引用156）              |  <- 三级
| 成果数: 论文45篇, 专利8项, 项目12个                        |  <- 统计
| 更新: 2024-09-15                                          |  <- 信任信息
+-----------------------------------------------------------+
```

**同名消歧**（UI9-FR-18）：
- 当检索结果包含同名学者时，必须展示区分信息：
  - 当前机构（必须）
  - 研究领域（必须）
  - 代表成果（推荐）
  - 成果数量统计（推荐）
- 不能只显示姓名，强制用户点击详情才能区分

**证据 B-E16**：80% 用户遇到同名困扰（问卷 Q5），需在列表阶段解决。

## 6. 分页交互

**分页方式**（方案 B 推荐）：
- 显示总数："共找到 1,234 条结果"
- 页码导航：[<] 1 2 3 ... 10 [>]
- 每页条数：10 / 20 / 50（下拉选择）
- 跳转到指定页：输入框 + "跳转"按钮

**特殊情况**：
- 总数超过 10,000 时，显示"约 10,000+ 条结果"（不伪造精确总数）
- 版本失效时（数据已更新），显示提示："数据已更新，请重新查询"

**证据 B-E17**：68% 用户期望看到精确总数（Q3），但需与技术可行性平衡。

## 7. 空结果与错误处理

### 7.1 业务空结果（0 条匹配）

```text
+-----------------------------------------------------------+
| 😕 未找到匹配结果                                           |
|                                                           |
| 你可以尝试:                                                |
| • 减少筛选条件 [清除全部筛选]                               |
| • 修改关键词: [________________] [重新搜索]                |
| • 浏览相关领域: [计算机科学] [生物医学]                      |
+-----------------------------------------------------------+
```

**要点**：
- 不能只显示文案，必须提供可点击操作
- 不能把空结果显示成系统错误
- 推荐相关领域或热门关键词

**证据 B-E18**：问卷 Q3，58% 用户期望空结果时有修正建议。

### 7.2 依赖失败

```text
+-----------------------------------------------------------+
| ⚠️ 暂时无法完成检索                                         |
|                                                           |
| 检索服务暂时不可用，请稍后重试。                             |
| 追踪编号: REQ-2024-XXXXX                                   |
| [重试] [返回首页]                                          |
+-----------------------------------------------------------+
```

**要点**：
- 明确区分依赖失败和空结果
- 提供追踪编号（如公共契约提供）
- 不显示技术栈细节

### 7.3 非法条件

```text
+-----------------------------------------------------------+
| ⚠️ 请检查检索条件                                           |
|                                                           |
| • 年份范围无效: 结束年份不能早于起始年份                      |  <- 定位到字段
| • 机构名称不存在: 请从下拉列表中选择                         |
+-----------------------------------------------------------+
```

**要点**：
- 错误定位到具体字段
- 说明如何修正
- 保留其他已填内容

## 9. 联想搜索与搜索历史（P1）

### 9.1 联想搜索

**触发条件**：输入 ≥3 个字符

**候选类型**：
- 作者姓名（高亮匹配部分）
- 机构名称
- 关键词/主题
- 历史查询

**交互**：
- 键盘上下键选择，回车确认
- 鼠标点击候选项
- 候选列表最多显示 8 条

**证据 B-E19**：52% 用户期望联想搜索（Q3）。

### 9.2 搜索历史

**保留规则**：
- 最近 5 次查询
- 本地存储（LocalStorage），不上传服务器
- 可清除全部历史

**显示位置**：
- 搜索框下方（未输入时显示）
- 历史项可点击直接执行

**证据 B-E20**：48% 用户期望搜索历史（Q3）。
