## 1. 证据说明与限制

PDF由问卷系统导出为5页图像型报告，原PDF无可用文本层，因此本文件依据逐页核对后的表格记录整理。问卷只提供选项小计和比例，不提供原始答卷、时间戳、受访者身份或开放题文本；不能据此推断总体用户比例，也不能替代针对科研人员和平台管理员的访谈。

样本量随题目变化：第1、2、16题有效填写35人；第3～13、15题有效填写30人；第14题有效填写23人；第17题未显示有效文本回答。多选题的各选项比例以该题有效填写人数为分母，比例之和可能超过100%。

## 3. 对 B 组调研需求的影响

| 证据 | 需求含义 | 对现有材料的处理 |
| --- | --- | --- |
| Q4中50%从关键词开始，Q5中76.67%使用主题关键词 | 全局关键词检索应是首要入口 | 支持 B-U02、B-UH01；保留领域入口作为第二入口 |
| Q6中76.67%按学科领域筛选，53.33%按成果类型、50%按年份 | 领域、类型、年份应进入核心筛选器 | 支持 B-U03～B-U05、B-UH01 |
| Q7中标题76.67%、年份53.33%是首看信息 | 结果卡片必须突出标题和年份 | 细化 B-U07 与 P2 结果列表字段 |
| Q8中63.34%至少偶尔使用高级搜索，但10%不知道高级搜索 | 可提供高级检索，同时保持简单搜索可用 | 支持 B-U02；高级入口需可发现并配合引导 |
| Q9中“搜不到成果”有时/经常66.67%，“结果太多”有时/经常63.34% | 召回、过滤和空结果反馈是主要痛点 | 提升 B-U06～B-U08 优先级；增加查询建议和筛选状态 |
| Q10中63.33%认为“搜不到”最影响效率 | 检索召回优先于装饰性功能 | 方案B开发先保证数据覆盖、分词和查询改写 |
| Q11中53.33%会换关键词，23.33%会减少筛选，20%会换平台 | 空结果应提供关键词和筛选调整建议 | 支持 B-U08；“推荐内容”仍需原型验证 |
| Q12中60%参考研究方向、60%参考代表成果 | 同名消歧至少展示领域和代表成果 | 强化 B-U11、P4 学者卡片信息 |
| Q13～Q14显示研究方向简介73.91%、成果列表60.87%最受关注 | 学者门户优先展示研究方向、简介和成果列表 | 强化 B-U12、P8；合作者信息为次级内容 |
| Q15中70%经常或偶尔查看统计 | 统计页有实际使用场景，但不是所有用户的首入口 | 保留 B-U13、P5；统计入口可从首页或导航进入 |
| Q16中电脑62.86%，手机28.57%，平板25.71% | 桌面优先，同时保留基本响应式能力 | 支持 B-U16 为体验增强，不据此改变核心范围 |
