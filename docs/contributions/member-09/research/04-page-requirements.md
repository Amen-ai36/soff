# 初步页面需求与信息架构（成员 9，方案 B）

状态：基于任务书和旅程推导的页面框架假设，尚未经真实用户验证或原型测试。待访谈与其他岗位材料完成后细化。本文输入第 5.2 节 UI 需求，以及第 10～12 周的线框图与原型设计。

## 1. 页面需求的用途与限制

页面需求用于确定平台核心页面、信息层级、导航结构和交互流程，为后续原型设计提供框架。

限制：本文是基于任务书、旅程地图和竞品分析推导的初步框架，不是最终设计方案。标记为 `[待确认]` 的页面、布局和交互必须经访谈、其他岗位确认或原型测试后，才能作为实现依据。

## 3. 核心页面需求

### P1. 首页

**用户目标**：快速开始检索或浏览任务。

**布局假设（方案 B）**：
- 顶部：全局检索框（突出位置）
- 中部：领域导航卡片（3～6 个热门领域） `[待确认]`
- 下部：机构排名 Top 10、领域热度、最新成果 `[待确认]`
- 底部：关于、帮助、数据来源

**关键元素**：
| 元素 | 功能 | 优先级 | 待确认事项 |
| --- | --- | --- | --- |
| 全局检索框 | 支持标题、作者、机构、关键词混合查询 | P0 | 是否提供高级检索入口 B-UQ03 |
| 领域导航卡片 | 点击进入领域详情页 | P0 | 首页展示几个领域 B-UQ01 |
| 机构排名 | 展示 Top 10，点击查看详情 | P0 | 排名依据与更新频率 |
| 领域热度 | 展示热门领域与成果数 | P0 | 热度判断依据 B-UQ01 |
| 最新成果 | 展示最近更新的成果 | P1 | 数量与筛选规则 |

**方案 A 与方案 B 的差异**：
- 方案 A：简洁检索入口，领域浏览为次要入口。
- 方案 B：检索 + 导航 + 排名 + 热门，四种入口并重。
- 建议：访谈验证 B-UH01、B-UH03，由成员 1、6 决定。

### P2. 检索结果页

**用户目标**：快速找到相关成果并判断相关性。

**布局假设**：
- 顶部：检索框（保留查询词）+ 筛选器总览
- 左侧：筛选器面板（成果类型、年份、机构、作者、领域） `[可折叠]`
- 中部：结果列表（标题、作者、机构、年份、来源、模拟标记）
- 右侧：排序下拉、视图切换（列表/卡片） `[待确认]`
- 底部：分页器 + 命中总数

**关键元素**：
| 元素 | 功能 | 优先级 | 待确认事项 |
| --- | --- | --- | --- |
| 筛选器面板 | 按类型、年份、机构、作者、领域组合筛选 | P0 | 是否支持引用数筛选 B-UQ02 |
| 排序下拉 | 相关度、时间、引用数 `[待确认]` | P0 | 引用数可用性 B-UQ02 |
| 结果列表 | 每条显示标题、作者、机构、年份、来源、模拟标记 | P0 | 标题长度与摘要策略 |
| 空结果提示 | 展示推荐领域、热门成果或修正建议 | P0 | 推荐内容来源 B-UH06 |
| 命中总数 | 显示总数与当前页范围 | P0 | - |

**交互流程**：
1. 用户输入查询词 → 显示结果列表。
2. 用户选择筛选器 → 实时更新结果 `[待确认是否需要"应用"按钮]`。
3. 用户切换排序 → 重新排列结果。
4. 用户点击成果卡片 → 进入成果详情页。
5. 空结果 → 展示推荐内容或修正建议。

### P3. 领域导航页

**用户目标**：按学科浏览成果，快速进入某个领域。

**布局假设**：
- 顶部：面包屑导航（首页 > 计算机科学 > 人工智能）
- 中部：领域卡片网格（每个领域显示名称、成果数、热度、代表图标）
- 下部：可展开的子领域列表 `[待确认层级深度]`

**关键元素**：
| 元素 | 功能 | 优先级 | 待确认事项 |
| --- | --- | --- | --- |
| 领域卡片 | 显示领域名称、成果数、热度 | P0 | 热度判断依据 |
| 面包屑导航 | 支持逐层返回 | P0 | 层级深度 B-UQ03（关联 Q05） |
| 子领域列表 | 可展开查看下级领域 | P0 | 是否需要"查看全部"入口 |

**方案 A 与方案 B 的差异**：
- 方案 A：领域浏览为次要入口，从检索结果筛选器进入。
- 方案 B：领域导航为独立一级入口，支持逐层浏览。
- 建议：访谈验证 B-UH01，由成员 1、6 决定。

### P4. 学者列表页

**用户目标**：查找特定学者，区分同名学者。

**布局假设**：
- 顶部：检索框（学者姓名）
- 中部：学者卡片列表（姓名、机构、领域、代表成果、头像 `[如有]`）
- 底部：分页器

**关键元素**：
| 元素 | 功能 | 优先级 | 待确认事项 |
| --- | --- | --- | --- |
| 学者卡片 | 显示消歧线索（机构、领域、代表成果） | P0 | 消歧线索优先级 |
| 头像 | 如有照片则显示，否则显示默认头像 | P1 | 照片来源与隐私 |
| 筛选器 | 按机构、领域筛选 `[待确认]` | P1 | 是否需要筛选器 |

1. 用户输入学者姓名 → 显示匹配学者列表。

3. 用户点击学者卡片 → 进入学者门户页。

### P7. 成果详情页

**用户目标**：查看完整元数据、来源出处、相关推荐。

**布局假设**：
- 顶部：标题、作者（可点击）、年份、来源链接、模拟标记
- 中部左侧：摘要、关键词、领域、引用数 `[如有]`
- 中部右侧：元数据卡片（类型、机构、项目、奖项）
- 下部：相关推荐列表 `[创新候选]` + 引用关系 `[待确认]`
- 底部：导出按钮（BibTeX、RIS） `[待确认]`

**关键元素**：
| 元素 | 功能 | 优先级 | 待确认事项 |
| --- | --- | --- | --- |
| 标题与作者 | 显示完整标题，作者可点击跳转门户 | P0 | - |
| 来源链接 | 跳转到原始数据源 | P0 | 来源可用性与合规 |
| 模拟标记 | 明确标注"此为模拟数据" | P0 | 标记位置与文案 |
| 摘要 | 显示完整摘要或前 300 字 + 展开 | P0 | 摘要长度策略 |
| 相关推荐 | 基于关键词、领域、作者推荐 3～5 条 | P1 | 推荐算法与理由展示 |
| 引用关系 | 显示引用与被引用成果 `[待确认]` | P1 | 引用数据可用性 B-UQ02 |
| 导出按钮 | 导出 BibTeX、RIS 格式 | P1 | 是否需要导出功能 B-U15 |

**交互流程**：
1. 用户从检索结果或推荐列表点击成果 → 显示详情页。
2. 用户点击作者 → 跳转学者门户页。
3. 用户点击相关推荐 → 跳转另一条成果详情页。
4. 用户点击导出 → 下载题录文件。
