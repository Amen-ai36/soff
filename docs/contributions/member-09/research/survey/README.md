# 问卷页面与二维码

配套 [../06-questionnaire.md](../06-questionnaire.md) 的可扫码实现。

## 1. 先看这里：该用哪个方案

微信扫码问卷的本质是"二维码指向一个手机端网页"，微信扫码只是用内置浏览器打开网址，没有额外技术要求。因此关键问题不是二维码怎么做，而是**页面放在哪、数据存到哪**。

| 方案 | 数据收集 | 国内访问 | 适合场景 |
| --- | --- | --- | --- |
| 问卷星 / 腾讯问卷 | 自动入库，可导出 Excel | 稳定 | **推荐**，正式发放 |
| 本目录 HTML + 自建接口 | 需自己写接口 | 取决于托管位置 | 已有服务器时 |
| 本目录 HTML + GitHub Pages | 无后端，仅本机暂存 | 微信内可能打不开 | 演示、答辩截图 |

**正式发放建议用问卷星或腾讯问卷**：把 [../06-questionnaire.md](../06-questionnaire.md) 第 4 节的题目录入，平台自动生成二维码，支持跳转逻辑、矩阵题、同一微信限填一次和数据导出。本目录的 HTML 用于自托管或离线演示。

GitHub Pages 在微信内置浏览器中存在访问不稳定的情况（域名在境外）。若要正式发放，不要依赖它。

## 2. 目录内容

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件问卷页，17 题，含跳转逻辑，无外部依赖 |
| `make_qr.py` | 二维码生成脚本 |
| `survey-qr.png` | 已生成的二维码（450×450），当前指向 GitHub Pages 地址 |

## 3. 生成二维码

```bash
pip install "qrcode[pil]"

# 用默认地址
python make_qr.py

# 指向你自己的问卷链接（换平台后用这个）
python make_qr.py https://www.wjx.cn/vm/xxxxxx.aspx

# 指定输出文件名
python make_qr.py https://www.wjx.cn/vm/xxxxxx.aspx wjx-qr.png
```

二维码内容就是那个网址，换地址后重新运行即可。**发放前必须用手机实际扫一次确认能打开**。

## 4. 页面功能

- 手机端优先布局，适配 iOS 安全区，支持深色模式
- 17 题，含两处跳转逻辑：Q2 选"几乎不查找"跳至 Q16；Q13 选"没有查看过"跳过 Q14
- Q9 矩阵题按行拆分展示，适合窄屏
- 互斥选项（如"以上都没有"）自动清除其他选择
- Q7、Q14 限选 3 项
- 顶部进度条按当前可见题数计算
- 未答必答题时定位到第一题并标红
- 提交后展示回答内容，可下载 JSON

无外部 CDN、无字体、无追踪脚本，断网也能打开。

## 5. 数据存储

`index.html` 顶部的 `ENDPOINT` 默认为空：

```javascript
var ENDPOINT = '';
```

留空时**不向任何外部地址发送数据**，回答只存在填写者本机的 localStorage，并在提交后展示供下载。这种方式无法真正回收数据，仅用于页面演示。

要实际收集，填入你自己的接口地址：

```javascript
var ENDPOINT = 'https://your-api.example.com/survey';
```

页面会以 `POST application/json` 提交，结构如下：

```json
{
  "submittedAt": "2026-09-22T11:30:00.000Z",
  "formVersion": "B-survey-v1",
  "answers": {
    "q1": "硕士研究生",
    "q3": ["期刊或会议论文", "专利"],
    "q9": { "搜不到想要的成果": "有时" },
    "q17": "希望支持按基金号检索"
  }
}
```

接口需要处理跨域（CORS）。**不要填入第三方免费表单服务**，那等于把填写者的回答交给未经团队确认的外部平台，与项目的数据合规要求冲突（S4 第 6 节）。若必须用第三方，先与成员 1、6 确认。

## 6. 本地预览

## 8. 已知限制

1. 微信扫码填写导致样本偏向手机用户，Q16 的设备题结果存在测量偏差，分析时需说明。
2. 便利抽样，存在自选择偏差，结果不能做统计推断。
3. 自托管页面无法保证同一人只填一次。
4. GitHub Pages 在微信内可能无法访问。
5. localStorage 方案下，清理浏览器数据会丢失未下载的回答。
