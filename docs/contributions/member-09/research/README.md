## 核心发现摘要

基于 50 份有效问卷（E-B-Q-001）：

1. ✅ **84%** 用户首选关键词检索，领域浏览为次要入口（10%）
2. ✅ **96%** 用户看标题判断相关性，70%看作者，60%看年份，56%看机构
3. ✅ **80%** 用户遇到过同名作者困扰
4. ✅ **96%** 关注数据来源，94%关注更新时间
5. ✅ **76%** 期望空结果时推荐相似关键词
6. ✅ **56%** 很少或从不使用统计分析功能
7. ✅ **90%** 期望在详情页看到认领入口
8. ✅ **98%** 认为模拟数据需要明确标记

详细分析见 [07-questionnaire-analysis.md](07-questionnaire-analysis.md)。
