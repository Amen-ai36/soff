# 评审门槛与验证边界

本轮检查分三层：文档/机器可读资产静态检查；临时SQLite设计试验；未来真实系统验证。前两层通过不会自动勾选AC3-01～24业务验收。

| 主题 | 本轮执行 | 运行实现后必须执行 |
| --- | --- | --- |
| 需求覆盖 | 16条M3需求、24项AC定义映射不漂移 | 同一公共夹具接口回归 |
| 认证 | OpenAPI敏感字段白名单/安全声明 | 正误凭据、退出/过期/禁用、CSRF、伪造角色、职责授权 |
| 认领 | 待审唯一、材料属主、回避、终态、唯一授权；各写点故障回滚 | 真实数据库双连接并发/隔离级别、死锁重试、服务端幂等和材料有效性 |
| 科研模型 | 同名保留、重复关系/来源拒绝、类型/年份、快照不可变 | 来源治理、字段许可、数据版本生成 |
| 检索统计 | 严格字段映射、公开投影白名单、源需求追踪 | 真实ES映射/召回/5-3-1排序、total、精确聚合、撤权/缓存竞争 |
| 发布 | 临时事务中指针/水位共同回滚，ID和哈希对账反例 | Worker崩溃、租约过期、停止/发布竞争、回执丢失、重建/回退 |
| 容量 | 写明百万目标、分档和测量方法 | 100万规范公开成果、真模拟分列、硬件/负载/P95/P99/峰值空间 |
| 契约 | JSON解析、引用、路径/参数/安全规则自检 | 正式验证器、公共OpenAPI契约测试、实际HTTP/端到端 |

## 人工评审清单

- [ ] 成员三本人审阅：个人维护白名单、版本和认领业务边界。
- [ ] 成员八交叉复核：E-R/表/索引/API及异步端口，接入唯一构件设计报告。
- [ ] 成员一/六共同确认：数据库/ES引擎版本、公共实体/API/枚举、材料规范、故障关闭范围及性能门槛。
- [ ] 成员二/七核对：稳定ID、来源证据、批次/租约/水位和事件字段。
- [ ] 成员四/九核对：幂等恢复、旧版本、无权/不存在、已保存待同步与任务状态展示。
- [ ] 成员五/十执行：真实契约、并发、恢复、百万规模与部署试验。

以上未发生的人工操作保留未勾选。本轮无人员签名、平台提交和真实业务测试；Mermaid源不等同CodeArts原生工程。公共契约变更正式步骤与回退见数据库设计及架构ADR输入。
