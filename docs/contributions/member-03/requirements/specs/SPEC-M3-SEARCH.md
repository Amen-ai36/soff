# SPEC-M3-SEARCH：检索、排序与公开查询 v0.1

状态：方案 A 可复现基线提案；用例 UC3-01/02；验收 AC3-05～12、24。输入输出与类型约束见 03-interface-constraints。本模块不负责上游清洗消歧、全文获取、索引架构选型。

## 1. 输入与候选范围

成果查询输入 q、四类类型、年份、机构/领域 ID、sort、page/page_size、可选数据版本。学者查询输入 name/alias、机构/领域和分页。仅用当前许可通过且允许公开的规范记录。同 work_id 不因来源多条重复展示。冲突版本不由检索任意选择，交治理。

公开详情按 ID 取权威可公开字段；门户按学者 ID 取四类公开关联，保留来源、更新时间和模拟标记。学者同名不合并；私人账号、证明、审核内部备注不返回。

## 2. 候选文本规则

以下只在查询时比较，不修改来源原文：Unicode NFKC，首尾去空白，连续空白合一，拉丁字符 casefold。按空白拆为不同 token；每个 token 须在任意一个可搜索字段中出现，token 间 AND。无空格中文按连续子串匹配。候选字段为题名、关键词和获准公开的摘要；不能用尚未授权的摘要提高命中或分数。作者名字使用学者检索，不以把所有名字拼入题名的方式冒充作者过滤。

不同过滤维度 AND；同维度多值 OR。年份范围排除未知年份；机构/领域用上游 ID。先限定合法公开集合、匹配、过滤，再排序、分页。空 q 不计算精确匹配奖励，返回过滤后的公开列表。

## 3. 排序规则

成果 relevance 的排序键依次为：

1. 非空 q 与规范化完整题名相等，精确匹配优先。
2. `score = 5*title_hits + 3*keyword_hits + 1*abstract_hits`，降序。每个不同 token 在每个字段只计一次，重复词/重复关键词不堆分。
3. 年份降序，未知年份末尾。
4. 规范成果 ID 的 Unicode 码点字典序升序，不猜测数字顺序。

year_desc/year_asc 仅按年份方向和 ID 升序，未知均末尾。学者 relevance 为完整姓名/别名精确匹配优先，再按不同 token 命中数降序、学者 ID 升序；学者不接受成果年份排序。白名单之外的排序拒绝。

此规则采用易手算的文本基线，与成员 8 的核心排序建议兼容，但不是已选定的 Elasticsearch 实现。后续采用 BM25/分词器必须显式评审算法、同分规则及夹具预期，不声称两种排序天然相同。权重是候选，不能当作用户已认可的相关性指标。

## 4. 分页、一致性与异常

page≥1、page_size 1～100，默认 20。total 为过滤后合法公开全集大小。空集 total=0；越界页空项但保留 total。固定版本、相同参数不重不漏，跨版本需要请求快照或提示刷新。

若可见范围已变更，旧版本不能绕过当前公开策略；不能只删当前页受限项却泄露原 total。需重新在权威公开范围计算或返回版本不可用。索引/权限依赖失败返回可识别故障，不返回伪造空集，不使用未授权备用来源。

## 5. 样例与验收

夹具 `fixtures/demo-data.json` 的 q=graph：W-A 精确题名优先，随后 W-B、W-C，W-D 不匹配，W-E 受限排除。分数 W-A=5、W-B=8、W-C=1，检验“精确优先”高于总分。学者同名 S-A/S-B 各自返回，不能按名字去重。

覆盖组合 AND/OR、四类、中文/拉丁规范化、重复 token、空 q、未知年份、非法范围、同分 ID、空集、越界、依赖失败及下线。后续排序单元测试与查询接口测试共同执行；小样例不证明 10,000 条性能。
