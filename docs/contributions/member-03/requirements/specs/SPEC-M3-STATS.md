# SPEC-M3-STATS：统计口径与基础分析 v0.1

状态：方案 A 候选；UC3-07；AC3-21～24。输入类型/时间/机构/领域与分析类别；输出分组/节点/边、计数、分母、unknown_count、规则版本、数据版本与更新时间。不实现预测、推荐或复杂中心性，不把基础关系和热点直接计为创新。

## 1. 统计集合

一次响应使用同一快照 S，先按与检索相同的公开范围和过滤条件选择，再按规范 work_id 去重。未知/冲突类型交上游治理，不偷偷归论文。重复来源行不多计，重复作者 ID/机构 ID/领域 ID 在单条成果内集合化。可见范围变化时旧快照不得继续泄露，必要时重算或提示版本失效。

## 2. 计算规则

| 分析 | 公式与口径 |
| --- | --- |
| 类型分布 | count(t)=S 内类型 t 的不同成果数；四类互斥，合计等于 |S| |
| 机构排名 | N(i)=包含机构 i 的不同成果数；使用成果发生时机构关联，不把学者当前机构套到历史成果。跨机构分别计 1，合计可大于 |S| |
| 并列名次 | rank(i)=1+计数严格高于 N(i) 的机构数，得到 1、1、3；同名次按机构 ID 升序展示 |
| 领域分布 | N(f)=包含领域 f 的不同成果数；分母 |S|。多领域占比和可超过 100%，无领域单列未知 |
| 专家关系 | 每条成果的规范作者 ID 去重后枚举无序二元组；边权为共同成果数，无自环/反向重复，保留支撑成果 ID |
| 年度热点 | 对年份 y、领域 f 计不同成果数；分母为 S 中年份 y 的不同成果数。按数量降序、领域 ID 升序展示年度分布与相邻年数量差 |

无机构记录不冒充真实机构参加排名。无年份记录进入 unknown_year_count，未限定时间时仍计入总分布，指定年份时排除。空分母时 share=null，不算 0/0；已知空集合 count=0。只有统计覆盖完整性确定时才能把缺少记录表述为现实不存在。

合作关系表示当前规范数据中的共同成果，不等同亲密关系或机构隶属，也不因学者同名建立边。本人隐藏展示关联不改变规范作者关系；正式纠错治理通过后才改变基础关系。热点只报告已收录数据的数量/比例变化，不推断因果或预测未来。

## 3. 手算夹具

W-A～W-D 公开，W-E 私有且完全排除。四类各 1。I-A=2、I-B=2、未知机构=1，两机构并列第 1。F-A=2、F-B=1、未知领域=1，份额 50%、25%。S-A 与 S-B 共同 W-A/W-B，边权 2，W-A 的重复 S-A 不多计。

2024 年 W-A/W-C 两条，F-A/F-B 各 1，分别 50%；2025 年 W-B 一条，F-A 为 100%；W-D 年份未知单列。2024 到 2025 的 F-A 数量差为 0，份额从 50% 到 100%，不能误报数量翻倍。

## 4. 异常与后续测试

非法范围拒绝；冲突规范版本交治理；服务不可用明确失败。若提供旧快照必须有 stale 标记与时点，且满足当前可见范围；不以旧值伪装实时。验收覆盖空集合、零分母、同名、重复来源/作者、多机构、多领域和年份缺失，后续配套统计单元测试与接口测试。10,000 条、吞吐、P95 与一致性延迟须真实实现后测量。
