## 进一步样本要求

后续增加全角拉丁、重复 query token、中文连续子串、多领域同成果、三机构并列及断号排名、同分不同 ID、受限摘要不得匹配、权限撤销与并发来源更新样本。边界预期以相应 SPEC 的规范化、集合去重、可见范围和原子性规则为准。

阶段静态检查只校验文件、引用、追踪覆盖和夹具手算一致性。接口、并发、故障注入、真人证明、10,000 条规模及性能均等待真实实现，不能从本包推断已通过。
