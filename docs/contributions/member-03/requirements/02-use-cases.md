# 业务用例说明

状态：方案 A 候选。认证是受限操作的前置条件，不画成每次重新登录的 include。查看详情可独立进入，不是每次检索必经步骤。全局图由成员 1/6 维护，本包只补充业务用例。

## UC3-01 检索成果与学者

- 参与者：访客及继承公开读取能力的用户；对应 M1-UC-01。
- 前置：公开检索服务可用；输入检索对象、关键词和过滤条件。
- 主流程：校验条件，按公开范围匹配，过滤，按规则排序，分页，返回条件、总数、版本和来源摘要。
- 备选：空关键词浏览公开列表；同名学者分别展示；越界页返回空项且保留总数。
- 异常：非法枚举/时间/页码返回字段错误；服务故障返回可追踪失败；跨版本翻页提示重新查询。
- 后置：不改变成果、学者或认领关系。排序规则见 SPEC-M3-SEARCH。

## UC3-02 查看成果详情与门户

- 参与者：访客；对应 M1-UC-02。
- 前置：目标存在且允许公开。
- 主流程：服务端检查当前可见范围，返回公开字段、来源/时间/模拟标记，门户按四类组织关联成果，显示认领结果。
- 备选：未提供字段显示未知；本平台收录零条明确限定范围；未认领可浏览。
- 异常：目标下线或无公开权限返回不可公开目标反馈，不泄露受限字段；来源链接失效仍显示来源记录但不声称链接正常。
- 后置：不产生授权，证明与申请人身份不进入公开内容。

## UC3-03 登录与退出

- 参与者：账号用户；对应 M1-UC-04。
- 前置：已有可用账号，账号创建方式不在本包中确定。
- 主流程：登录校验凭据并建立会话；退出使当前会话失效。
- 异常：错误凭据通用提示；禁用/过期会话拒绝写；认证依赖故障不按成功处理。
- 后置：登录不自动认领门户；退出后旧会话不能再次写入。

## UC3-04 提交认领及查询本人申请

- 参与者：登录用户；对应 M1-UC-05、06。
- 前置：门户可申请；用户了解证明用途与可见范围。
- 主流程：选择门户，提交本人材料引用和说明，校验，创建待审核申请，返回编号；本人查询状态和理由。
- 备选：相同幂等请求返回原结果；驳回补充后新建申请并关联旧 ID。
- 异常：他人材料/空材料/门户占用拒绝；同用户同门户已有待审申请返回既有申请或重复冲突；身份标准未满足不能默认通过。
- 后置：提交后无维护权；敏感材料受限。详见 SPEC-M3-CLAIM。

## UC3-05 审核门户认领

- 参与者：授权且非申请人的管理员；对应 M1-UC-07。
- 前置：申请待审；取得受限材料访问权；读取当前版本。
- 主流程：核验来源与同名风险，选择通过/驳回并填理由，原子检查版本与门户占用，保存决定/审计；通过同时建立授权。
- 备选：证据不足有理由驳回，申请人补充后新申请；通知单独异步执行。
- 异常：自审拒绝；并发版本或占用冲突返回最新状态；事务失败不提交任何局部结果；通知失败保留决定并标记重试。
- 后置：通过对应有效授权，驳回无新增授权，终态不能普通审核回退。

## UC3-06 维护本人门户和成果关联

- 参与者：具备目标门户授权的学者；对应 M1-UC-08。
- 前置：会话和门户授权有效，客户端带读取版本。
- 主流程：读取允许字段，编辑个人简介/兴趣，服务端复查授权和版本，保存留痕；成果补录、字段纠错进入治理。
- 备选：移除本人展示关联仅影响本人门户，不删除成果本体或他人关联。
- 异常：他人门户、未知字段、过期版本拒绝；来源更新与人工值冲突转治理；索引失败保留待同步。
- 后置：保存权威版本或产生治理请求编号，不把待审核补录冒充已公开。

## UC3-07 查看统计分析

- 参与者：访客；对应 M1-UC-03。
- 前置：可取得固定公开快照和规则版本。
- 主流程：校验过滤范围，按规范成果 ID 去重，计算类型/领域/机构、关系/年度热点，返回口径、分母、未知数和版本。
- 备选：空集合数量为 0，比例无分母时为未知；多机构、多领域分别去重计数。
- 异常：输入错误拒绝；冲突数据交治理；依赖故障不返回伪造 0 或未标记旧值。
- 后置：不合并同名学者，不把统计相关性写成因果或未来事实。

## UC3-08 提交及处理业务纠错

- 参与者：授权学者提交，治理管理员处理；对应 M1-UC-11 的业务部分。
- 前置：目标和来源可定位，治理权限与具体处理规则由数据岗位协同。
- 主流程：提交错误关联/字段说明，记录目标版本与证据引用，管理员核查，记录决定，批准后更新权威版本并触发同步。
- 异常：权限不符拒绝；来源与人工修改冲突保留双方证据，不强行覆盖；处理失败维持原权威数据。
- 后置：记录治理结果和发布状态；不在本包定义去重/消歧复核算法或全套治理状态枚举。
