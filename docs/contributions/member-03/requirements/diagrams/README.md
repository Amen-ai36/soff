## 转换检查

- 初始伪状态进入待审核表示“有效创建”，非法提交不产生实例。
- 通过转换的守卫含非本人、版本一致、门户空闲；转换动作原子保存审核、授权与审计。
- 驳回需要理由且不授予维护权；证据不足不是自动通过。
- 失败/冲突不强制回退最新权威状态，因此图未画易误读的 PENDING 自环。
- 已通过/已驳回是当前申请终态。新申请是新实例，不在旧申请上画驳回到待审核的箭头。
