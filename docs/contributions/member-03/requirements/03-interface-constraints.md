# 接口需求语义约束

状态：成员 3 候选，非正式 OpenAPI。字段名称为表达语义的草案，URL、错误码、角色枚举、数据库字段与具体认证机制均未冻结。

## 1. 数据与类型建议

- 所有实体 ID 为不透明非空字符串；不得用姓名或账号 ID 代替学者 ID。
- 成果类型使用 paper/patent/project/award 候选值；上游未知类型转治理，不擅自当论文。
- 时间戳含时区；年份为整数或未知。null 表未知，空列表表当前范围无关联，0 表已知计数为零。
- 用户/审核者从服务端会话获得；客户端不得写角色、认领所有者或申请者身份。
- 来源、处理批次、公开范围、模拟标记和数据版本由上游提供；缺失关键来源不得悄悄生成可信来源。

## 2. 业务操作

| 操作 | 输入语义 | 输出语义 | 核心约束 |
| --- | --- | --- | --- |
| 认证/退出 | 凭据/当前会话 | 会话建立或失效结果 | 不回显凭据，不把账号控制权当门户授权 |
| 成果检索 | q、类型、年份上下限、机构/领域 ID、排序、分页、可选快照版本 | items、total、分页、数据版本、更新时间 | 字段白名单，仅公开数据 |
| 学者检索 | 姓名/别名、机构/领域、分页 | ID、公开姓名、区分线索、分页/版本 | 同名保持不同 ID，不返回私有联系方式 |
| 详情/门户 | 目标 ID、成果栏目及分页 | 公开字段、四类成果、来源、收录范围、认领结果 | 不嵌入证明、审核私有备注或申请人账号 |
| 申请/查询 | 门户 ID、本人材料引用、说明、幂等键/申请 ID | 申请编号、状态、版本、本人可见理由 | 本人或职责内管理员可读 |
| 审核 | 申请 ID、决定、理由、预期版本、幂等键 | 决定及新版本 | 排除自审，提交时再次校验占用 |
| 维护/纠错 | 目标、允许字段或纠错说明、预期版本 | 权威版本或治理请求编号、发布状态 | 区分已保存、待审核与待同步 |
| 统计 | 时间/类型/机构/领域、分析类别、可选版本 | 分组/节点/边、分母、未知计数、算法/数据版本 | 与公开检索范围一致，响应内同快照 |

## 3. 参数与分页候选

关键词最多 200 字符；年份整数 1000～9999，起始不大于结束。页码从 1 开始，默认每页 20，允许 1～100。不同过滤维度 AND、同维度多个 ID 为 OR；空数组视为该维度不限定。指定年份范围不匹配未知年份。未知领域筛选需明确选项，不能把 null 偷换成真实领域 ID。

排序白名单及未知值顺序见 SPEC-M3-SEARCH。越界页 items=[]、total 不变。请求携带旧数据版本时若无法提供对应快照，返回版本冲突提示，不悄悄跨版本承诺分页不重不漏。total 以当前可公开候选集计算，不能包含仅在旧索引可见的受限成果。

## 4. 权限、并发与错误

写入次序为会话、操作权限、对象授权、参数/版本、业务约束、原子写入。并发业务约束必须在最终提交时再次检查，不能只依赖表单加载时检查。

同主体同操作同幂等键同参数重试返回已存结果；同键不同参数返回冲突。幂等保留期待确认，超期仍靠待审唯一约束、门户唯一授权和终态保护维持正确性。普通重试不得改变已有审核终态。

| 错误类别 | 可选 HTTP 映射 | 用户反馈 |
| --- | --- | --- |
| 输入不合法 | 400 | 可定位字段与允许范围 |
| 无有效会话 | 401 | 登录或刷新会话 |
| 已认证但操作无权 | 403 | 权限不足 |
| 不存在/不可公开/私有读取无权 | 404 | 无可访问对象，不泄露存在性 |
| 版本、占用、幂等键冲突 | 409 | 保留原输入，刷新状态后再决定 |
| 请求过密 | 429 | 重试提示，阈值待确认 |
| 依赖不可用 | 503 | 失败及追踪 ID，不伪装空结果 |

以上映射仅提案，不发明已批准机器码。响应不得含堆栈、密钥或证明正文。

## 5. 上下游衔接

成员 2/7 输出规范成果/学者/机构/领域 ID、来源与批次、规则版本、公开策略与未知值。检索/统计不再次根据名字合并，不在本模块解决强标识冲突。

审核通过时申请状态、门户授权和最小审计原子提交。资料/关联变更提交后保存权威版本，再触发索引/统计同步；同步失败可追踪重试。撤下或改私有后，公开读取需按权威策略复查，旧缓存/索引不得继续泄露；无法核验时失败关闭该结果。最终 total 与分组需在合法可见集合计算，不能只过滤一页后仍返回含受限项的总数。

证明类型/大小、存储、授权读取、保留期限和具体会话实现待构件设计。注册、自助提升管理员、撤回、申诉、门户转让不由本包默认开启。
