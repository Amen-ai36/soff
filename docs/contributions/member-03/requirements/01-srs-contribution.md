版本 0.1，2026-10-12。全部细化规则为方案 A 建模候选，公共规则尚未冻结。来源编号见本包 README。

## 1. 功能边界与术语

账号是登录主体，学者是来源数据形成的科研实体，门户是其公开展示，认领申请是授权请求，审核通过后才建立门户维护授权。认领不转移成果产权，不证明来源数据完全真实，也不授予论文全文公开权。四类成果为论文、专利、项目、获奖；每类栏目必须存在，当前收录零条不等于现实中没有成果。

成果、学者、机构、领域使用规范 ID 区分。姓名相同不意味着同一学者，来源记录重复不意味着不同成果。公开结果与受限证明材料分离。采集/治理变更通过版本与同步状态影响检索和统计。

## 3. 跨功能约束

- 未认领门户可公开浏览；本人申请状态和证明不作为门户公开内容。
- 维护本人门户与删除公共成果是不同操作。个人移除展示关联不销毁成果、不抹去其他作者关联或来源证据。
- 认证只确认账号控制权，审核确认门户维护资格；正式证明标准仍需共同确认。
- 查询只能在可公开数据范围内执行；权限变更优先于旧缓存或索引结果。
- 专家关系与热点基础统计属于任务书范围，不能仅以其存在宣称创新。最短路径、推荐或预测需另行选择和编写 SPEC。

## 4. 非功能和验收边界

| 维度 | 本岗位要求 | 验证方式 |
| --- | --- | --- |
| 权限与隐私 | 会话、角色、对象授权分别校验；证明/密钥不进入公开响应、索引和日志正文 | 权限负向场景、响应与日志字段检查 |
| 可复现性 | 同一输入版本和规则得到稳定排序和统计；同分有明确 ID 规则 | 合成夹具与后续单元测试 |
| 可靠性 | 写入失败无部分授权；依赖失败不冒充空数据；通知失败不撤销已提交审核 | 故障注入与审核查询 |
| 可追溯 | 来源版本、审核依据、修改人、前后版本和同步状态可查 | 抽样反查与治理场景 |
| 可用性 | 认领前说明材料用途；错误定位字段；空结果与失败有不同反馈 | 与成员 4/9 页面走查 |
| 规模/性能 | 后续以不少于 10,000 条成果演示检索和统计；统一硬件和脚本报告 P95 | 集成验收，本包不宣称已达标 |
