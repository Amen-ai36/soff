# SPEC-M8-STATS：统计口径与基础分析 v0.1

关联 M8-STAT-01/02/03、M8-NFR-01/04/06；用例 UC08-06；来源 R10。状态：建议口径待公共评审。

## 输入、范围与输出

输入时间、类型、机构、领域范围；在与检索相同的公开规范化成果快照 S 上计算，按 work_id 去重。输出数值、分母、unknown_count、计数方式、data_version 和 updated_at。上游负责实体消歧，统计不自行把同名合并。排除不可公开记录；模拟数据必须可识别。基础关系和热点属于必做范围，预测与复杂网络指标不在本规范内。

## 算法

1. 类型分布：四类互斥，count(t)=|{w∈S:type(w)=t}|；总和等于 |S|。未知/非法类型属于上游异常，本规范不静默归为论文。
2. 机构排名：N(i)=去重的包含机构 i 的成果数。机构来自成果发表/发生时的规范化机构关联，不把学者当前机构追溯套用到旧成果。多机构成果在每个机构内计 1，跨机构总和可超过总成果数。无机构单列 unknown_count，不冒充真实机构参加排名。并列采用相同名次且后续跳号（1、1、3），展示顺序按机构 ID 升序。
3. 领域分布：每个领域内按成果去重；多领域允许交叉，所以各领域占比之和可大于 100%。分母为 |S|，无领域单列未知数；与机构过滤的 AND/OR 语义同检索。
4. 专家关系：对每条成果去重后的 scholar_ids 枚举无序二元组，按 ID 排序确定边；权重为共享的不同成果数；不生成自环、重复方向边，不把仅同机构视为合作。边可返回支撑成果 ID。无作者不生成边。
5. 领域热点：对每年 y 和领域 f 统计去重 count(y,f)，同年分母为 S 中年份为 y 的总成果数；share(y,f)=count/denominator。按数量降序、领域 ID 升序列出；给相邻年差量，不用缺失年份补当年。基础趋势仅陈述分布，不暗示预测或因果。
6. 空集合或某年分母为 0 时 count=0、share=null；界面显示“无数据”，不算 0/0。无年份记录统计 unknown_year_count，仍计入未限定年份的总分布。
7. 一次响应必须使用同一快照；来源重复行不重复增量计数。若发现相同 ID 的冲突版本则先由治理决定权威记录，本统计模块不得任意挑选。

## 小规模可复核样例

fixtures/demo-data.json 为合成数据，公开成果 W01～W04 共 4 条，W05 非公开排除。每类各 1；机构 I01=2、I02=2，unknown=1，排名均为 1；领域 F01=2、F02=1，unknown=1。A01—A02 共享 W01、W02，边权为 2，W01 中重复 A01 只计一次。

2024 年公开 W01、W03 共 2 条，F01/F02 各 1、占比各 50%；2025 年仅 W02，F01 占比 100%；W04 无年份，unknown_year_count=1。该样例同时暴露重复作者、跨机构加总误解和未知年份误填问题。

AC08-14～19、AC08-24。缺失字段按明确 unknown 处理；非法过滤拒绝；依赖失败返回错误，不以旧数伪装实时值；若允许旧快照，必须明确 stale 标记和时间。数据规模、性能、ES 一致性在后续真实实现上另测，本阶段不报告通过率或覆盖率。
