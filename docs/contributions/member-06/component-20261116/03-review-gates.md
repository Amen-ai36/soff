# 构件设计评审标准（成员6供稿）

| 门禁 | 通过条件 | 证据 |
| --- | --- | --- |
| G1 需求追踪 | 每个构件职责能追到 SRS/SPEC 和用例 | 编号映射表 |
| G2 边界 | 权威数据、公开投影、受控材料和长任务边界清楚 | 组件图/接口表 |
| G3 一致性 | 认领—审核—授权、版本—索引—统计术语一致 | 术语核对表 |
| G4 安全 | 服务端鉴权，证明材料不随公开检索泄漏 | 权限矩阵与异常案例 |
| G5 数据质量 | 去重消歧可追溯，失败/停止不推进公开水位 | 流程、状态和审计记录 |
| G6 可靠性 | 异步任务可恢复且幂等，投影失败保留旧公开版本 | 重试/恢复测试记录 |
| G7 可验证性 | 接口、数据库、算法和部署各有真实验证命令或平台证据 | 测试/部署附件 |
| G8 变更控制 | 公共 API、实体、字段和验收变更有成员1/6共同确认 | 决策记录 |

任何一项只有“候选方案”而无证据时，状态写“待复核”，不能写“已完成”。
