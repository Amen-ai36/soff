# SPEC-M8-SEARCH：检索与排序规范 v0.1

关联 M8-SEARCH-01/02、M8-NFR-01/03/04；用例 UC08-01；来源 R06。状态：待确认提案。

## 目标与范围

在公开规范化成果和学者上提供可解释的过滤、排序和分页。包括四类成果及学者同名区分；不负责采集、去重/消歧算法、全文下载或数据库/ES 选型。

## 输入输出

采用接口约束建议。q/name 为字符串，建议最大 200 字符；年份 1000～9999 整数或缺省，起始不大于结束；page≥1，page_size 1～100。类型和 sort 白名单，不接受未知字段。成果按 ID 返回题名、类型、年份、公开作者/机构/领域、来源与模拟标记；学者返回学者 ID、公开姓名、机构、领域。

## 候选集和算法规则

1. 候选集为当前可公开的规范化记录；重复来源合并属于上游职责，检索不得以不同来源重复展示同一成果 ID。
2. 文本先 Unicode NFKC、去首尾空白、合并空白，拉丁字符不区分大小写。多词用空白拆分，每个词须在可搜索字段之一出现（AND）；中文不含空格的一段按连续子串匹配。此为课程可复现基线，复杂中文分词另做对照，不暗中改变语义。
3. 成果搜索字段：题名、关键词、摘要；作者姓名走学者检索，避免名称串误匹配多人。学者按姓名别名匹配，辅以机构和领域过滤，同名保持各自 ID。
4. 不同过滤维度 AND，同维度 OR。时间过滤排除未知年份；机构/领域按 ID，不按显示名猜归属。
5. relevance 模式：成果题名与完整 q 规范化后相等者优先；其后按 title_token_hits×5 + keyword_token_hits×3 + abstract_token_hits×1 降序；每个不同 token 在每个字段最多记一次，不按出现频率堆分。空 q 时分数为 0，不计算完全相等奖励。
6. 同分按年份降序（null 末尾），再按 ID 的 Unicode 码点升序。学者 relevance 模式为规范化完整姓名精确匹配优先，再按不同 token 命中数降序、ID 升序；学者不适用年份排序，收到该模式拒绝。
7. 成果 year_desc 按年份降序、ID 升序，year_asc 按年份升序、ID 升序；两者 null 都在末尾。ID 比较是字典序而非数字猜测。
8. 先过滤再排序，最后分页；total 是过滤后全集大小。静态数据版本内不重不漏。跨版本翻页应提供版本提示或快照协议，不能声称任意更新下页码分页仍稳定。

该基线是待评审的业务算法，不代表 Google Scholar 或 OpenAlex 内部算法。若采用 BM25 等排序，需要显式替换本规范及预期结果后再实现。

## 异常与验收

空数据成功返回 items=[]、total=0；越界页同样空但 total 保持；非法类型/范围/页码拒绝；服务失败返回依赖错误而非空集合。覆盖 AC08-01～06 和 AC08-20。至少 10,000 条和性能目标由后续集成验收，不由小夹具证明。

夹具 fixtures/demo-data.json 的 q=graph：W01 完全匹配优先，W02 次之，W03 第三；W04 不匹配；W05 虽匹配但非公开须排除。score 辅助值 W01=5、W02=8、W03=1，完全匹配优先级高于加权分数。可检出“只按总分排序”的错误实现。
