## 3. 设计衔接事项

| 编号 | 事项 | 影响 | 分析结论 |
| --- | --- | --- | --- |
| Q-D01 | 公开成果容量门槛存在 10,000 条与百万级两种口径 | 验收门槛、容量假设 | 分析模型不绑定容量；采用哪一口径时只替换需求参数 |
| Q-D02 | UpdateRecord 采用独立表或并入来源版本历史 | 后续数据库设计 | 分析阶段保留为来源变化日志，不指定物理落库方式 |
| Q-D03 | 索引投影失败时的门户提示文案 | 检索与门户交互 | 业务状态使用「待同步」，展示文案由 UI 统一 |
| Q-D04 | 人工维护字段清单与治理边界 | 源更新冲突处理 | 统一规则为来源更新不覆盖人工值，冲突进入治理队列 |
| Q-D05 | B 组批次/检查点粒度 | 两组对照 | 与 A 组相同的幂等与提交边界要求，具体粒度按来源能力配置 |
