# SPEC M7 RESOLVE 去重消歧与机构归一化规范

编号SPEC-M7-RESOLVE，版本0.1。关联M7-DEDUPE-01、M7-AUTHOR-01、M7-INST-01。状态：待共同评审。原则是证据不足时少合并，不能用高召回掩盖不同作者或不同成果被误合并。

## 1 输入输出

输入为清洗后候选记录、原值/来源、强标识、类型、版本以及经过批准的作者和机构映射。输出规范化成果ID、来源到成果ID映射、字段证据列表、合并提议/冲突队列及作者/机构关联。内部参考字段名只用于说明，不定义公共数据库。

## 2 成果去重

同类型内按以下强键判定。不同类型永不自动合并。

| 类型 | 自动匹配强键 | 不自动合并的情况 |
| --- | --- | --- |
| paper | 相同规范化DOI；或同来源相同Work ID/DBLP key | DOI不同或标题/类型严重冲突；仅同标题 |
| patent | 相同局别+公开号+kind code | 同申请号但不同公开/授权阶段；同专利族 |
| project | 同资助方/来源命名空间+项目号 | CORDIS/NSF/NSFC恰好数字相同 |
| award | 公告体系+年度+奖项类别+项目编号 | 同名项目跨年度获奖；不同奖项类别 |

重跑同来源键且载荷相同为unchanged；同来源键载荷变化为update候选，不新建重复成果。强键相同但非空强标识互斥、类型冲突或核心标题比较键不一致，进入review，不自动覆盖。标题差异可能是合理版本变化，但必须有人或已批准来源规则判断后更新。

无强键时，以规范化标题、年份、至少一位已明确关联作者和venue形成候选阻塞组；本期保守基线只生成提议，不自动合并。弱匹配阈值及模糊算法可作为B组后续优化，须经共享样例评审。

不使用无约束并查集导致传递误合并：A和B共享一个ID、B和C共享另一个ID时，先检查整个候选簇中同一强标识命名空间有无多个互斥值。任何矛盾让整个受影响簇进入复核，不把C静默吸入A。

## 3 字段选择与稳定ID

相同规范值合并来源证据。非空值与未知值并存时选有依据的非空值；同字段不同非空值保留候选及各自时间，不按文件最后一行覆盖。来源优先级必须版本化且经评审；本包没有授予任何来源全字段最高权威。

引用数保留来源与观察时点，不相加、不跨来源取最大；若公开选择OpenAlex作为显示源则只取其该版本值，DBLP缺失不覆盖它。来源失效/撤销时重新计算获准投影，不沿用已撤销字段。

新成果ID由持久化ID注册映射分配，不从临时行号生成；重跑和输入顺序变化不换ID。合并保留选定存续ID和旧ID重定向；拆分由管理员确认关系归属并分配新映射，旧记录和审核证据保留，查询/门户/统计重建相应版本。

## 4 作者消歧

优先使用经校验ORCID或同来源作者ID，以及已经人工批准的跨源映射。ORCID先检查格式和校验位；通过格式不等于身份已认证，来源ID也可能出错。自动关联仍需无互斥身份ID及明显上下文冲突。

同名、同机构、共同作者、研究领域或年份只作辅助证据，不单独赋予同一身份。ORCID不同者不自动合并；同名无强证据保持多个学者ID，并向成员8提供可公开的机构/领域区分线索。一位作者可多机构、多时期变化；不能因机构变化就拆成新人，也不能因相同机构就合并同名人。

低置信度关联提交人工复核；未确认关系不用于门户归属或合作网络边。管理员记录选择、证据、日期和规则版本。消歧不触发门户认领通过、账号绑定或写权限。

## 5 机构归一化

可信ROR或同来源机构ID精确匹配优先；没有标识时只使用已批准、带版本的别名表。仅去空白或大小写可生成比较键，不据名称相近自动跨机构合并。大学、学院、附属医院及历史更名分别处理，父子关系不能替代身份相等。未匹配机构保留来源名称及未解析状态，不凭常识猜所属学校。

## 6 质量指标与验收

AC07-08至15覆盖强键、跨类型、冲突、传递冲突、同名和机构。质量评估另外使用人工独立标注：去重以候选记录对为单位，TP为正确合并、FP为误合并、FN为应合并而未合并；Precision=TP/(TP+FP)，Recall=TP/(TP+FN)，F1=2PR/(P+R)。零分母报告不适用，不填100%。记录对样本需有正负例，不能只挑已成功合并记录。

作者消歧另用作者提及到学者实体映射单位，并在含同名、跨机构和缺标识的独立样本报告Precision/Recall/F1。原调研提出的200条/对、F1≥0.95等阈值为待议目标，不是本包已经通过的指标。规则样例通过不证明真实数据质量。
