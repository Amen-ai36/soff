# SPEC M7 CLEAN 数据清洗规范

编号SPEC-M7-CLEAN，版本0.1。关联M7-CLEAN-01、M7-FIELD-01、M7-NFR-01/02。状态：待成员2、1、6评审。本规范先于任何生产实现；本包校验脚本只是规则样例检验。

## 1 目标与输入输出

将来源适配器提供的记录清洗为可进入去重模块的候选记录。不处理网页爬取、全文下载、身份认证或检索排名。

输入至少含成果类型、来源键、原始标题、获取时间、使用依据及字段权限；可选含DOI、局别/公开号、日期、作者/机构关系和领域。原记录及原字段保留在允许的存储范围内。输出为清洗值、字段级来源、规则版本、异常原因和处置结果valid/quarantine/filtered。输出候选不代表已获准公开。

## 2 确定性规则

1. 文本比较键使用Unicode NFKC、去首尾空白、连续空白归一为一个空格、拉丁字符casefold。显示值仅规范空白，保留有意义大小写、重音和汉字。不把繁简、拼音、译名自动视为等价，不删除标题所有标点后强行合并。
2. 必要字段是类型、来源键、标题及获取时间/依据记录。标题为空或纯空白隔离；未知类型隔离。未知发表年可为null，不为满足完整率而填当前年。
3. DOI仅去除大小写不敏感的doi:、https://doi.org/、http://doi.org/或dx.doi.org前缀，解码URL百分号并转小写。须匹配10.<4至9数字>/<非空后缀>，无空白、查询串或片段；保持尾部标点，不盲删可能属于DOI的字符。格式合法不代表注册或可解析，真实解析另验。非空但非法的强标识隔离，不自动置null继续合并。
4. 专利公开号保留局别、数字和kind code，空白可删除、字母大写；申请号另存。A1、B1等不同文献阶段不自动合并为一条。是否按专利族归并属于待决业务规则。
5. 年份1000至9999，布尔值不当作整数；null为未知，0和无法解释字符串非法。日期按来源声明的格式严格解析，校验闰年和月日；保留year/month/day精度。项目起始晚于结束隔离。未来起始日期可以是计划项目，不仅因未来日期而判为错。
6. 引用数为非负整数或null，布尔值、负数、无法确定格式非法。缺引用数不补0。货币金额若导入须保留币种和原精度，不跨币种直接相加。
7. null表示未知，[]仅表示确认无关联，0表示确认数量零。来源未给作者/机构列表时用未知标志或null，不伪造空关联。姓名不造唯一ID，缺关系不自动补人。
8. 领域保留来源体系和代码，按批准映射表映射公共领域；未知进入unknown并记录原因。无摘要不由AI补写科研事实。
9. 公开字段必须经过字段级许可过滤；未知使用依据进入许可待审隔离。restricted/pending/denied不进入公开输出。模拟标记不得在清洗时丢失。

## 3 错误和边界

文件编码损坏、CSV列不匹配、JSON/XML格式错误视为输入包错误，停止该包，保留已处理计数和原因；不逐字替换乱码后假装完整成功。单行错误隔离并保留来源定位，不能静默删除。XML适配器禁用外部实体和网络DTD自动解析；许可允许时从已核验本地DTD解析。文件大小、每批条数和保留期由部署配置评审，不在此猜测生产阈值。

## 4 验收

AC07-01至07覆盖文本、DOI、日期、缺失值、必填和引用数；AC07-16覆盖许可。相同输入与版本的比较键相同；原值可追溯。正式实现还须覆盖坏编码、超大输入、XXE、单位/日期精度和未知分类，本包小样例不能证明所有边界已实现。
