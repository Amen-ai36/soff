## 候选语义源稿与生成预览

- [转移表](collection-transitions.json)是状态与事件的唯一生成输入。
- [PlantUML源稿](collection-state.puml)可编辑并供实际绘图参考。
- [SVG预览](collection-state.svg)包含全部转移编号；编号含义见源稿和下表。
- [生成器](../../scripts/build_state_model.py)从转移表生成源稿和预览，两者均须与SPEC共同评审。

| 编号 | 流转 | 事件和约束 |
| --- | --- | --- |
| T01 | 待执行到运行中 | 开始，权限和来源条件有效 |
| T02 | 待执行到已停止 | 管理员停止，无网络采集 |
| T03 | 运行中到成功 | 完成处理并确认发布版本，不能仅HTTP200 |
| T04 | 运行中到重试等待 | 临时失败或429，仍有预算 |
| T05 | 运行中到失败 | 认证/访问/许可拒绝，不自动重试 |
| T06 | 运行中到失败 | 不可恢复错误或耗尽重试 |
| T07 | 运行中到安全停止中 | 停止先于完成获准，不再发起新请求 |
| T08 | 安全停止中到已停止 | 到达安全边界并撤销未提交写入 |
| T09 | 重试等待到运行中 | 等待到期，符合Retry-After及预算/权限 |
| T10 | 重试等待到失败 | 预算耗尽或人工结束等待 |
| T11 | 重试等待到已停止 | 管理员停止，取消定时重试 |
| T12 | 失败到待执行 | 管理员显式重试，新attempt保留旧日志 |

失败可以受控重试，因此不是UML最终伪状态；成功/已停止无自动出边，不会被迟到响应覆盖。STOPPING是候选内部细化状态，需1/6确认是否公开展示。转移表记录静态守卫，但实现必须实际检查守卫，不能仅按事件名无条件跳转。
