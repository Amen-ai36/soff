# 构件边界与公共约束

## 构件分区

| 构件 | 责任 | 输入输出边界 | 负责人协作 |
| --- | --- | --- | --- |
| Source Adapter | 读取公开或模拟来源，记录许可、版本和水位 | 来源配置→原始观测和来源证据 | 2/7 |
| Collection Orchestrator | 创建任务、尝试、批次、停止、重试和检查点 | 任务请求→任务状态与处理批次 | 2/7 |
| Normalize and Deduplicate | 类型校验、规范化、去重、作者消歧、机构归一 | 来源观测→规范候选、冲突和处置账目 | 2/7 |
| Authoritative Store | 保存账号、学者、成果、关系、申请、决定、授权和审计 | 业务命令→权威版本事实 | 3/8 |
| Search Projection | 构建和刷新公开检索投影 | 已批准公开版本→索引文档和发布水位 | 3/8 |
| Query and Statistics | 合法全集上的检索、分页、排序和统计 | 查询条件→结果、total、统计口径和版本 | 3/8 |
| Claim and Portal | 认领、审核、门户展示和授权内维护 | 身份与申请→决定、授权和审计 | 3/8/4/9 |
| Web and Admin UI | 页面、导航、前端状态和非敏感草稿 | 用户操作→公共应用接口请求 | 4/9 |
| Operations | 配置、健康检查、指标、告警、备份和恢复 | 运行事件→可观测记录与处置 | 5/10 |

## 公共契约约束

1. 账号、学者、门户、申请、审核决定和授权使用独立标识；提交申请不产生维护权。
2. 来源记录、规范成果和参与关系分开计数；真实、模拟、四类成果和未知分类单独披露。
3. 任务、执行尝试、批次、更新记录和发布版本分开建模；重试不得重复计数。
4. 认领通过时决定、终态、唯一有效授权和必要审计必须共同成功或共同失败。
5. 查询和统计使用同一公开版本及完整合法集合；不能只过滤当前页后沿用旧total。
6. 证明材料只进入受控访问，不进入公开响应、搜索索引或日志正文。
7. 构件之间通过端口或适配器调用，禁止跨边界直接修改另一构件的内部表。
8. 公共字段、状态、分页、错误语义和ID规则须经成员1、6共同确认；本目录不冻结新API。

## 方案差异位置

A组可以采用任务表加Worker、候选评分或特定索引策略；B组可采用不同内部实现。差异只影响内部实现与支撑材料，不能改变公共公开口径、权限边界、幂等语义和验收标准。
