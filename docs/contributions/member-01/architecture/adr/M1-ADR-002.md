# M1 ADR 002 权威状态与检索投影

日期2026-11-05；状态Proposed；对应AN-I02/05/06/07、R05/R08/R14。

## 决定建议

事务存储保存权威状态和待投影工作，后台幂等更新ES。认领决定、授权及审计在同一业务原子边界保存；查询版本只有在公开ID集合核验后发布。同步处理可采用事务内可靠工作记录或outbox候选机制，详细表和事件字段由3/8设计。

## 备选与理由

直接双写数据库与ES可能出现一侧成功一侧失败；数据库与ES跨系统事务增加实现和恢复难度。可重放投影以权威数据重建，符合分析阶段“已保存”和“已发布”的区分。ES刷新可见性依据见调研文档。

## 故障与后果

处理重复、乱序及删除：按规范身份和单调版本执行，旧更新不得覆盖新结果，撤下事实保留可追溯版本；失败保留重试及告警。人工修正冲突转治理。当前公开策略在结果、total与统计全集上生效；策略服务不可用时关闭受影响公开读取。该安全控制需要专门的全量排除查询和负载验证。

## 迁移与验证

先建候选索引并核对集合，再切读版本；失败保留旧版查询能力，但仍执行当前公开策略。回放中重复、乱序、断电、索引不可用、撤下数据和并发审核分别验证Q02/Q03/Q05。成员2/3/7/8提供实现细化，成员1/6联合确认。
