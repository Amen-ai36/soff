# M1 ADR 003 公共端口与模块替换

日期2026-11-05；状态Proposed；对应R13及双组方案§8/9。

## 决定建议

两组实现共同核心功能，外部公共契约与规范身份共同确认，内部模块通过适配器接入。最终选择主版本后逐模块迁移优秀实现，保留追踪映射和回切点。

## 备选与理由

机械合并两套系统会同时引入状态、存储、认证及依赖冲突；只选整套实现会丢失另一组可复用优势。端口适配支持以同一夹具比较模块，同时控制迁移范围。

## 兼容与迁移

先清点输入输出、状态、权限、分页、错误及ID语义；对停止恢复等差异建立映射提案，由1/6确认。只读影子比较后，一次迁移一个模块并保持单一权威写入方。数据先做可逆映射与备份演练，再切流；回切不删除已提交事实，应按版本重放或补偿。

## 验证及影响

每次执行契约回归、越权、失败恢复和同版本计数比较，对应Q06。增加适配层维护成本，但可单独定位行为差异。此ADR不创建新API或数据库字段，契约冻结记录另行共同维护。
