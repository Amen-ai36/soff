# M1 ADR 001 模块化核心与独立Worker

日期2026-11-05；状态Proposed；责任成员1，联合决策成员1/6。

## 背景与决定建议

需求R04/R08/R11同时要求长时任务可恢复和短时审核结果一致。建议在线业务采用分层模块化核心，采集及投影任务由独立Worker执行，任务状态持久化。

## 备选与理由

全量微服务增加跨服务一致性和部署管理；全部任务在Web请求内执行会占用在线资源且难以恢复。模块化核心保留较小运维面，Worker隔离数据负载，适合先完成完整链路。

## 后果与迁移

需限制模块跨表写入，并维护Worker重试、积压和健康观测。先建立模块端口及任务存储，再接Worker；有独立扩容证据后提新ADR拆服务。回切Worker时停止领取新任务并排空或安全停止当前批次，避免新旧写入方并行。

## 验证及确认

联合查询与采集负载、Worker重启、批次安全停止和重复执行试验，对应Q01/Q04。测量通过及1/6共同确认后转Accepted；当前为设计提案，无测试成绩或签字。
