# 功能实现基线

## 公共核心功能

两组必须实现同一组核心功能：认证与权限、成果采集或导入、清洗标准化、去重与作者消歧、机构归一化、百万级数据规模目标、成果检索/过滤/分页/排序/详情、学者门户、门户认领、管理员审核、采集任务管理、基础统计，以及完整的数据链路演示。

## 实现边界

A组可以采用自己的数据库、检索、异步和前端实现，但不能单方面改变公共 API、业务实体、错误码、分页格式、状态枚举、验收口径或数据合规要求。公共契约变更必须由成员1和成员6共同确认。

## 完成定义

一个功能只有同时具备实现代码、对应 SPEC、可复现运行命令、测试证据、异常路径说明和人工复核记录，才可在台账中标记“完成”。仅有设计文档、截图、接口 JSON 或静态校验不能标记为完成。

## 规模口径

百万级是目标，不得把目标写成已实现结果。演示时须分别披露真实数据、模拟数据、去重后数量和测试样本范围。
