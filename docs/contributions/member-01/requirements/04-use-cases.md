## 2. 关键用例摘要

### M1-UC-01 检索成果与学者

- 前置条件：公开检索数据可用。
- 主流程：选择检索对象 -> 输入关键词和过滤条件 -> 校验 -> 匹配 -> 排序 -> 分页 -> 展示总数、条件和数据版本。
- 备选流程：空关键词作为公开列表；无匹配返回明确空结果；同名学者保留不同 ID。
- 异常流程：非法条件返回字段错误；检索依赖失败返回服务失败，不返回伪造空列表。
- 后置条件：系统数据不被修改。

### M1-UC-05 提交门户认领

- 前置条件：用户已登录，门户存在且允许申请。
- 主流程：选择门户 -> 提交证明材料引用和必要说明 -> 校验材料归属、重复申请及门户占用 -> 创建待审核申请 -> 返回申请编号。
- 备选流程：已存在相同待审申请时返回既有申请；驳回后补充材料创建新申请并关联历史。
- 异常流程：材料不完整、他人材料、门户已占用或幂等键冲突时拒绝。
- 后置条件：只产生申请，不产生门户维护授权。

### M1-UC-07 审核门户认领

- 前置条件：管理员已授权，申请处于可审核状态，审核者不是申请者。
- 主流程：读取材料和上下文 -> 核验证据 -> 选择通过或驳回 -> 校验版本与门户占用 -> 保存决定和审计；通过时同步建立授权。
- 备选流程：材料不足时有理由驳回；申请者可补充后另行申请。
- 异常流程：并发处理、门户已被占用或持久化失败时不覆盖最新结果；通知失败不回滚已提交决定。
- 后置条件：通过状态和授权同时成立，或驳回状态无授权且有理由。

### M1-UC-08 维护本人门户与成果关联

- 前置条件：当前账号对目标门户有有效授权。
- 主流程：读取当前版本 -> 修改允许的个人字段或提交成果补录/纠错 -> 校验 -> 保存或进入治理 -> 记录来源与版本。
- 异常流程：他人门户、过期版本、非法字段被拒绝；采集值与人工值冲突进入治理，不静默覆盖。
- 后置条件：共享成果本体不会被单个学者无授权删除。

### M1-UC-09 管理采集任务

- 前置条件：管理员已授权，数据源和合规状态已批准。
- 主流程：配置来源与范围 -> 校验 -> 创建待执行任务 -> 启动 -> 采集 -> 记录进度 -> 成功后触发处理和入库。
- 备选流程：限流或临时失败按规则退避重试；管理员可停止允许停止的任务。
- 异常流程：未授权来源、无效配置或达到熔断条件时拒绝或失败；部分成功必须显示分项计数。
- 后置条件：任务状态、批次、错误和结果可追溯。

### M1-UC-10 执行清洗、去重和消歧

- 前置条件：存在可处理批次和已版本化规则。
- 主流程：结构校验 -> 字段清洗和标准化 -> 重复候选生成 -> 去重决策 -> 作者/机构消歧 -> 许可检查 -> 写入规范数据和处理证据。
- 备选流程：低置信度候选进入人工复核，不确定数据保留处理状态。
- 异常流程：规则失败或写入失败时记录失败位置，可安全重试且不重复计数。
- 后置条件：每条规范记录可追溯到来源记录、规则版本和决策。

## 3. 用例关系说明

- “查看成果详情与学者门户”是检索后的可选行为，不使用 `include` 强制每次检索都查看详情。
- “提交门户认领”“查询本人认领状态”“维护本人门户与成果关联”和所有管理用例都要求有效会话。认证属于前置条件，不画成 `include 登录与退出`，避免误解为每次操作都重新执行登录。
- “已认领学者”继承“登录用户”，“登录用户”继承“访客”的公开读取能力。
- “定时调度器”只能触发已批准任务，不拥有审核、数据治理或配置批准能力。
- 清洗、去重和消歧可由采集成功后触发，也可由管理员对指定批次发起；不能把实现顺序画成业务参与者继承关系。
