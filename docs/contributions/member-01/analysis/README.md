## 使用边界

- 当前是分析级概念模型，不冻结数据库表、API字段、状态枚举或技术栈。类名是本包局部分析别名，正式名称由成员1/6共同确认。
- 按用户最新课堂反馈，采用不少于**1,000,000条去重、规范化、可公开检索成果**的目标。`a`分支历史材料中的10,000条不能作为最终门槛；本包不宣称已导入或压测。
- 详细的学者/机构/成果/领域类图、认领/检索时序图仍由成员3/8完成；采集入库时序图由成员2/7完成。本包给出整体连接规则及交接输入，不代签这些成员的成果。
- 本次仅整理分析材料，无核心业务代码生成，不新增核心代码AI日志。人工审阅、成员6联合确认和平台建模操作必须由实际执行人完成并记录。
