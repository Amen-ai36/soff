# 方案 A 低保真线框稿

版本：0.1

状态：需求讨论用草稿，未做真实用户任务测试，不代表最终视觉设计或已实现页面。

## 5. 窄屏适配原则

```text
+------------------------------+
| 平台名称            [菜单]   |
+------------------------------+
| [成果 v]                     |
| [关键词....................] |
| [搜索]  [筛选]               |
| 条件: [领域 x] [类型 x]      |
+------------------------------+
| 题名                         |
| 年份 | 类型                   |
| 作者                         |
| 来源                         |
+------------------------------+
| 题名                         |
| ...                          |
+------------------------------+
```

- 侧栏筛选在窄屏变为可关闭面板，但已生效条件仍在结果上方可见。
- 主操作保持可触达，不使用横向表格承载核心信息。
- 页面不固定到某个前端框架或组件库；实现阶段依据选定技术栈重建。

## 6. 原型任务测试脚本

1. 从首页查找“大语言模型”相关论文，并限定领域、类型和年份。
2. 在两个同名学者中依据领域和代表成果找到目标门户。
3. 找不到成果时修改关键词或移除筛选，不离开当前任务。
4. 在学者门户找到研究方向和成果列表，并说明认领状态含义。
5. 进入认领申请，指出材料用途、提交后的状态和何时获得维护权。

观察记录只写实际行为、困难和修订，不诱导用户回答，也不编造受访者原话。
