1. 成员 6 汇编统一 SRS 时，将 `UI4-*` 局部编号映射为正式编号；未决项保留负责人和状态。
2. 成员 1 复核本包与系统边界、用例和验收基线的一致性。
3. 成员 3/8 确认检索、认领、审核和维护的业务规则后，成员 4/9 再冻结页面字段和交互。
4. 成员 5/10 只把已确认内容放入唯一 PPT 和追踪表，不把线框稿或提案写成已实现功能。
5. 本次仍是非核心代码文档整理；使用记录已在 `docs/ai/model-a/usage-log.md` 留痕，后续生成前端核心代码时继续按项目规则记录。
