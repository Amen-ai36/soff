- 使用 `UI4-AN-*` 表示交互分析条目，`UI4-ST-*` 表示前端状态条目，`UI4-EX-*` 表示异常反馈条目。

## 3. 一致性检查结果

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 公开检索空集与故障 | 一致 | 两组检索 SPEC 均要求依赖失败不得返回伪造空集 |
| 同名学者处理 | 一致 | 保留不同实体 ID，页面显示区分信息 |
| 认领最小业务状态 | 一致到三态提案 | `PENDING/APPROVED/REJECTED` 共同出现；仍待公共确认 |
| 驳回后重提 | 一致 | 旧申请保持终态，新建申请并保留历史 |
| 管理员自审 | 一致禁止 | 页面禁用且服务端必须拒绝 |
| 并发审核 | 一致 | 冲突方刷新权威状态，不覆盖已提交结果 |
| 通知失败 | 一致 | 不回滚已保存的审核决定 |
| 门户维护边界 | 一致 | 个人展示关联与公共成果本体分开 |
| “需补充材料/撤回” | 未冻结 | 不纳入本包业务状态，仅列为待决项 |
| 查询版本、错误码、接口字段 | 未冻结 | 本包只定义用户可观察行为 |
