## 3. 建模边界

1. `初始、加载、成功、空结果、失败、无权限、编辑中、提交中、冲突` 是前端视图状态，不写入认领申请业务状态。
2. 认领业务状态只引用成员 3/8 共同出现的 `PENDING / APPROVED / REJECTED` 候选语义；“需补充材料、撤回、申诉、转让”继续作为待决项。
3. 图中的“检索服务、认证服务、认领服务”是分析级职责边界，不代表已批准的 URL、HTTP 方法、错误码或部署服务划分。
4. 前端隐藏按钮不能替代服务端授权；页面收到冲突或过期版本时必须重新读取权威状态。
5. 本包不修改已完成的统一 SRS，不声明成员 9 已复核，也不声明需求分析评审已经通过。
