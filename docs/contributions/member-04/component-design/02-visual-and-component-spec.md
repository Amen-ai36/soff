# 视觉与组件规范

状态：A 组候选视觉规范；最终品牌色、字体和组件库待成员 1/6、9 共同确认。

## 1. 设计令牌

| 令牌 | 候选值 | 用途 |
| --- | --- | --- |
| `font.body` | 系统无衬线字体，16px，1.5 行高 | 正文和表单 |
| `font.heading` | 系统无衬线字体，20/28/32px | 页面标题和区域标题 |
| `space` | 4/8/12/16/24/32px | 间距和布局节奏 |
| `radius` | 4px（输入）、8px（卡片/对话框） | 轻量边界 |
| `color.text` | 深色正文 + 次级灰 | 正文/辅助信息 |
| `color.surface` | 白色内容面 + 浅灰页面底 | 内容层级 |
| `color.action` | 高对比蓝色 | 链接、主操作和焦点 |
| `color.success/warn/error` | 绿/琥珀/红，配文字和图标 | 状态辅助，不单靠颜色 |
| `focus` | 2px 高对比外描边 | 键盘焦点 |

令牌值是实现输入，不是公共品牌规范；颜色变更仍须保持普通文字 4.5:1、大字号 3:1 的候选对比度门槛。

## 2. 核心组件

| 组件 | 必备状态 | 行为约束 |
| --- | --- | --- |
| `SearchBox` | 初始、输入、非法、提交中 | 显式标签；提交中防双击 |
| `FilterBar` | 未应用、已应用、清除、窄屏展开 | 条件可移除；清空不误删关键词 |
| `ResultCard` | 完整、部分缺失、下线 | 缺失显示“未提供”；不渲染私密字段 |
| `StatusPanel` | 加载、空、失败、过期、无权限 | 文字说明 + 恢复动作 + 可感知状态 |
| `ClaimForm` | 编辑、字段错、提交中、结果未知 | 敏感材料受控；失败保留非敏感输入 |
| `DecisionDialog` | 确认通过、确认驳回、冲突 | 明确对象和后果；焦点回收 |
| `VersionBanner` | 当前、待同步、已失效 | 显示更新时间/版本语义 |
| `DataBadge` | 真实、模拟、未知、未提供 | 用文字表达，不只用颜色 |

## 3. 文案和可访问性

- 页面标题、控件标签和按钮名称表达任务，例如“重新查询”“查看已有申请”，不用内部错误名。
- 异步状态放在 `aria-live` 等可感知区域；关键结果不只通过短暂 toast 告知。
- 图标按钮有可访问名称；表单错误与控件程序化关联；对话框打开后焦点进入、关闭后回到触发器。
- 颜色只做辅助，成功/警告/错误同时显示图标或文字；错误文本不截断。
- 表格和图表提供可读数值/列表替代，创新图不以视觉关系作为唯一信息载体。
