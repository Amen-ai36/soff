# 创新功能 UI 接入说明

状态：候选设计，编号 `UI4-INNOVATION-CANDIDATE`；需成员 1/6 和课程评审共同选择后才进入正式范围。

## 1. 候选范围

候选为学者门户中的“合作关系探索”和“年度领域变化”两个互补视图。它们建立在公开成果、规范学者 ID、领域和年度统计之上；不替代基础检索、机构排名、成果类型分布或领域基础统计。

## 2. 页面结构

```text
学者门户
└─ 公开分析（候选）
   ├─ 合作关系：时间范围、领域、最小支撑成果数 -> 图形 + 支撑成果列表
   └─ 年度领域变化：年份范围、领域 -> 趋势图 + 计数、分母、unknown_count、规则版本
```

## 3. 状态和隐私

| 状态 | UI 表现 |
| --- | --- |
| 未启用 | 隐藏入口或显示“候选功能未开放”，不影响门户主流程 |
| 加载 | 保留图表尺寸，显示条件和加载状态 |
| 有数据 | 图形 + 可读列表 + 数据版本/更新时间/口径 |
| 数据不足 | 说明缺少公开支撑，不画推断关系 |
| 空结果 | 明确无匹配，允许修改条件 |
| 依赖失败/版本失效 | 与空结果分离，提供重试或重新查询 |

创新视图只使用公开投影；认领证明、私有联系方式、审核内部备注不得进入响应、缓存、图表 tooltip 或导出。未知领域、真实 0 和未提供分母必须分别表达。

## 4. 验收前提

正式验收需要共同确认创新选择、关系边权、年度分母、允许的时间范围、空数据夹具、性能预算和可访问替代表格。在决定完成前，本文件只作为 UI 接入和风险边界输入。
