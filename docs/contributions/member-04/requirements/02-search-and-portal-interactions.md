# 检索、详情与学者门户交互需求

状态：成员 4 方案 A 交互提案。检索字段可用性、排序算法、统计口径和接口语义由成员 3/8 提供并经成员 1/6 确认；本文只规定用户可观察行为。

## 1. 检索主流程

```text
选择检索对象 -> 输入关键词 -> 可选设置过滤/排序 -> 提交
-> 显示条件、总数和数据版本 -> 浏览结果 -> 打开成果详情或学者门户
```

| 编号 | 交互需求 | 优先级 |
| --- | --- | --- |
| UI4-FR-04 | 成果检索应允许组合成果类型、年份、机构和领域条件；已生效条件可见并可单独移除或全部清除 | P0 |
| UI4-FR-05 | 成果结果项应突出题名和年份，并展示成果类型、作者、来源/机构等可用的辅助判断信息 | P0 |
| UI4-FR-06 | 结果页应显示当前检索对象、关键词、过滤条件、排序方式、总数和分页位置 | P0 |
| UI4-FR-07 | 空结果应提供修改关键词、减少过滤条件和重新搜索的直接操作；依赖失败必须使用不同反馈 | P0 |
| UI4-FR-08 | 成果详情应展示公开元数据、作者/机构关联、来源、原始链接、更新时间和数据状态 | P0 |
| UI4-FR-09 | 学者检索遇到同名时，应优先显示机构、研究领域和代表成果等区分信息，并保留不同学者实体 | P0 |
| UI4-FR-10 | 学者门户应优先展示研究方向/简介和按论文、专利、项目、获奖分组的成果，可显示公开统计和认领状态 | P0 |
| UI4-FR-11 | 统计页面应同时提供图形结论和可读数值，并显示时间范围、统计口径、未知类和更新时间 | P0，深度待确认 |

## 2. 简单搜索与高级搜索

### 2.1 简单搜索

- 首页保留单一主搜索框，默认对象和占位提示必须明确。
- 搜索对象至少区分成果和学者，不能用同一结果卡片混合后不标类型。
- 空关键词是否允许作为公开列表由统一 SRS 决定；UI 必须与最终规则一致。
- 最近搜索、联想词和热门词不是当前 P0，不得替代真实检索结果。

### 2.2 高级搜索

问卷中 22/30 的用户至少偶尔使用高级搜索，因此入口需要可发现，但高级表单不能阻塞简单搜索。候选字段包括主题关键词、题名、作者、机构、期刊/会议名称和项目/基金编号；是否全部进入一期取决于成员 3/8 对索引字段的确认。

高级条件应支持：

1. 明确字段标签和示例，不只依靠占位文字。
2. 提交前展示已填写条件，提交后能返回修改。
3. 非法年份范围、未知类型等错误定位到字段。
4. 清空高级条件不删除当前关键词，除非用户明确选择全部重置。

## 3. 过滤、排序和分页

| 主题 | UI 行为 | 待决事项 |
| --- | --- | --- |
| 过滤 | 领域、成果类型和年份优先；机构按数据可用性提供 | 筛选即时生效还是点击“应用”由原型测试决定 |
| 排序 | 当前排序名称和方向可见；切换后回到第一页 | 相关度、时间、引用等排序口径由成员 3/8 冻结 |
| 分页 | 显示当前位置并保留检索条件；版本失效时提示重新查询 | 页码/游标协议属于公共接口，不在此定义 |
| 总数 | 只显示服务端可解释的总数或近似标识 | 不伪造精确总数 |

## 4. 结果信息层级

### 4.1 成果结果项

| 层级 | 信息 | 缺失处理 |
| --- | --- | --- |
| 一级 | 题名、发表/完成年份 | 未知年份显示“年份未提供” |
| 二级 | 作者、成果类型、期刊/会议或项目/专利来源 | 缺失字段不留无标签空白 |
| 三级 | 摘要片段、机构、领域、引用或其他统计 | 未确认或不可用时不显示虚构数字 |
| 可信度 | 数据来源、更新时间、状态 | 来源缺失应标记待治理，而非隐藏 |

### 4.2 学者结果项

至少展示姓名、机构、研究领域和代表成果摘要中的可用信息。姓名不能成为唯一定位依据；点击后按不可变 ID 进入门户，但 ID 的格式不在 UI 文档中规定。

## 5. 成果详情

成果详情应支持：

- 识别论文、专利、项目或获奖类型。
- 展示公开字段、作者/机构关联、领域、来源链接和最近更新时间。
- 区分“未知”“未提供”“真实为 0”。
- 提供学者门户、相关成果或反馈入口时，不把候选关联写成已核实事实。
- 原始链接不可用时说明状态，不自动跳转到不受信任地址。

## 6. 学者门户

门户首屏按问卷证据采用以下优先级：

1. 姓名、当前机构、研究方向和简介。
2. 论文、专利、项目、获奖四类成果入口及列表。
3. 成果数量和引用等公开统计（仅在口径可说明时显示）。
4. 合作者或关系信息（属于次级信息，需与统计/创新范围一致）。
5. 门户认领状态和符合权限的认领/维护入口。

未认领门户可以展示公开数据，但不得暗示平台已验证本人身份。已认领标识只说明平台认领关系通过，不等于平台为全部成果真实性背书。

## 7. 检索状态矩阵

| 场景 | 标题 | 说明 | 可用操作 |
| --- | --- | --- | --- |
| 无匹配 | 未找到匹配结果 | 保留当前关键词与过滤条件 | 修改关键词、清除筛选 |
| 依赖失败 | 暂时无法完成检索 | 说明可重试；显示公共契约提供的追踪信息 | 重试、返回首页 |
| 非法条件 | 请检查检索条件 | 在对应字段显示原因 | 修改后重新提交 |
| 版本失效 | 数据已更新 | 原分页结果不再稳定 | 使用原条件重新查询 |
| 部分字段缺失 | 信息未完整收录 | 对单个字段标记“未提供” | 查看来源、提交反馈 |
