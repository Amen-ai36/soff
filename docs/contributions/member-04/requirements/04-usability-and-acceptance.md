## 2. 验收场景

### UI4-AC-01 简单检索

- Given：访客位于首页，公开检索服务可用。
- When：选择“成果”，输入关键词并提交。
- Then：进入结果页，显示关键词、结果总数或明确的总数语义、当前排序、数据版本及结果列表。

### UI4-AC-02 组合筛选

- Given：结果包含多年份、领域和成果类型。
- When：用户组合选择领域、类型和年份。
- Then：已生效条件全部可见，可逐个移除；结果与条件一致，清除筛选后保留关键词。

### UI4-AC-03 结果信息层级

- Given：成果记录具有题名、年份及部分辅助字段。
- When：用户扫描结果列表。
- Then：题名和年份为一级信息；缺失辅助字段显示“未提供”或不渲染对应项，不显示虚构值。

### UI4-AC-04 业务空结果

- Given：检索服务正常，但没有记录匹配条件。
- When：查询完成。
- Then：页面明确显示无匹配，并提供修改关键词和清除筛选操作；不显示系统故障文案。

### UI4-AC-05 检索依赖失败

- Given：检索依赖不可用。
- When：用户提交查询。
- Then：页面显示可识别的失败和重试入口，不显示“0 条结果”，并按公共契约显示追踪信息。

### UI4-AC-06 同名学者区分

- Given：存在两个姓名相同但实体 ID 不同的学者。
- When：用户检索该姓名。
- Then：两条结果均保留，并展示可用的机构、领域和代表成果信息帮助区分。

### UI4-AC-07 学者门户

- Given：学者门户存在且允许公开。
- When：访客打开门户。
- Then：优先看到研究方向/简介及四类成果入口；缺失类型显示明确空状态；私有认领材料不可见。

### UI4-AC-08 未登录认领

- Given：访客位于可申请认领的门户。
- When：点击申请认领。
- Then：页面说明需要登录；登录成功后返回目标门户或安全恢复申请上下文，不把登录视为认领成功。

### UI4-AC-09 提交认领

- Given：登录用户填写满足公共规则的材料。
- When：提交成功。
- Then：页面显示申请编号、提交时间和待审核状态；门户维护入口仍不可用。

### UI4-AC-10 认领表单错误

- Given：必填说明缺失或材料不符合公共规则。
- When：用户提交。
- Then：错误定位到字段，其他非敏感输入保留；不产生成功申请。

### UI4-AC-11 重复申请

- Given：用户已有同一门户的待审核申请。
- When：再次发起认领。
- Then：页面打开或链接到既有申请，不显示第二个成功编号。

### UI4-AC-12 审核冲突

- Given：管理员正在查看的申请已被其他授权管理员处理。
- When：当前管理员提交决定。
- Then：页面提示记录已更新并加载权威状态，不覆盖已提交结果。

### UI4-AC-13 门户维护权限

- Given：用户仅拥有门户 A 的维护授权。
- When：尝试修改门户 B 或删除共享成果本体。
- Then：操作被拒绝；页面不暗示可以通过隐藏控件绕过服务端权限。

### UI4-AC-14 未知值

- Given：记录缺少年份、领域或统计分母。
- When：页面渲染详情或统计。
- Then：使用“未知/未提供/无数据”等明确表达，不显示误导性的 0 或 0%。

### UI4-AC-15 键盘操作

- Given：用户不使用鼠标。
- When：完成首页检索、结果筛选、打开门户和进入认领表单。
- Then：焦点顺序合理、焦点可见、所有核心操作可触发，弹层不会困住或丢失焦点。

### UI4-AC-16 响应式布局

- Given：分别使用 1366x768 和 360x800 的代表性视口。
- When：执行检索、查看门户和填写认领表单。
- Then：文字、控件和主操作不相互遮挡；不因横向溢出导致关键内容不可访问。

### UI4-AC-17 隐私隔离

- Given：认领申请含证明材料和私有联系方式。
- When：未授权访客打开门户、检索结果或构造材料访问请求。
- Then：页面和响应不泄露材料、联系方式或可推断其存在的内部错误细节。
