# 普通用户访谈提纲

> 状态说明（2026-10-12）：本文是访谈工具，不是已执行访谈或用户结论。当前问卷事实与证据限制见 [问卷元信息与样本复核](05-questionnaire-confirmation.md)；真实访谈或原型测试完成后须另存匿名记录和修订依据。

## 1. 访谈目标

了解用户查找、判断和使用公开数据时的行为、需求及痛点。

## 2. 访谈对象

建议访谈 5—8 人，包括教师、研究人员、学生、机构人员和普通数据平台用户。

## 3. 开场说明

本次访谈预计持续 20—30 分钟，仅用于产品设计和课程项目分析。你可以拒绝回答任何问题，也可以随时结束访谈。未经同意，不会公开个人信息。

## 4. 背景问题

1. 你平时是否需要查找公开数据？
2. 通常通过哪些网站或工具查找？
3. 查找数据的频率是多少？
4. 最近一次查找数据是为了完成什么任务？
5. 通常是个人使用还是团队共享？

## 5. 使用行为与痛点

1. 你通常先搜索关键词还是先浏览分类？
2. 搜索结果中哪些信息最重要？
3. 你如何判断数据是否可信？
4. 是否遇到过数据重复、过期或来源失效？
5. 查找数据时最耗时的环节是什么？
6. 你希望有哪些筛选条件？

## 6. 详情页问题

1. 查看详情时最先关注什么？
2. 哪些信息必须放在页面上方？
3. 是否需要查看原始来源？
4. 是否关注更新时间和数据状态？
5. 哪些情况会让你认为数据不可信？

## 7. 认领需求

1. 是否有过证明数据属于自己或所属机构的需求？
2. 认领时需要提交哪些材料？
3. 最担心认领流程中的什么问题？
4. 希望如何查看申请进度？
5. 可以接受多长的审核时间？

## 8. 统计与反馈

1. 是否需要查看数据数量、来源分布和时间趋势？
2. 更喜欢数字、表格还是图表？
3. 发现错误时是否愿意提交反馈？
4. 反馈表单中哪些字段是必要的？
5. 是否需要查看反馈处理进度？

## 9. 原型验证

1. 你认为这个页面的主要用途是什么？
2. 如果查找数据，你会先点击哪里？
3. 哪些信息不清楚？
4. 哪个操作最难找到？
5. 如果只能保留三个功能，你会选择哪些？

## 10. 结束问题

1. 还有哪些需求没有被问到？
2. 数据平台最重要的特点是什么？
3. 上线后最希望优先改进什么？
