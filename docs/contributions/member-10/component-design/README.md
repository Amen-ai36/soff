# 成员10｜5.5 构件设计阶段质量保障供稿（B组）

**岗位：测试、部署与 AI 证据；阶段：第10—12周。**

根据双组并行方案，成员3/8负责数据库、E-R图、核心表、索引、ES映射、缓存、RESTful API和异步任务接口的设计；成员4/9负责UI原型与视觉规范；成员2/7负责采集、清洗、消歧、增量更新等构件。成员5/10共同负责检查设计可测试性、整理评审记录、支撑材料和PPT。

因此，本目录不代写其他岗位的构件设计，而是提供**跨构件质量检查、可测试性要求、评审记录模板、测试支撑材料与汇报PPT**，交由成员8汇编唯一正式《数据库设计说明书》《接口设计说明书》及其他构件设计文档。成员3负责复核。

## 文件

- `01-component-testability-review.md`：数据库、检索、接口、ETL、UI和统计构件的可测试性检查。
- `02-design-review-record.md`：设计评审议程、问题台账、决议模板；未实际召开会议的栏目保持待填写。
- `03-component-test-evidence-plan.md`：构件级测试支撑材料、夹具和证据追踪计划。
- `04-ab-component-quality-merge-checklist.md`：A/B构件设计统一检查及合并前质量门禁。
- `templates/review-issue-log.csv`：可直接维护的问题跟踪表。
- `templates/test-evidence-register.csv`：可直接维护的测试证据登记表。

本目录是个人贡献材料，不是第二份正式构件设计说明书，也不证明测试已执行或评审已通过。
