# B组候选部署与运行保障方案（成员10供稿）

状态：架构设计候选稿，待成员1/6统一架构审核、实际部署操作者核验。

## 1. 设计目标与约束

本方案负责回答“B组候选系统部署在哪里、组件如何通信、如何测试和保障运行”。设计目标：

1. 支持公开成果检索、学者门户、认领审核、统计分析及管理后台。
2. 支持公开数据源/模拟数据进入采集、清洗、入库、检索和统计的完整链路。
3. 将在线请求与耗时采集/ETL任务隔离，避免后台任务阻塞用户请求。
4. RDS保存权威业务状态；OBS保存原始批次及受控对象；CSS承载可重建的公开检索索引。最终技术实现需与成员3/8的存储和一致性设计一致。
5. 通过环境隔离、最小权限、日志脱敏、健康检查、备份和回滚降低演示与运行风险。

任务书明确列出华为云 ECS/CCE、RDS、OBS、CSS 作为部署架构设计涉及的组件。具体采用 ECS 还是 CCE、实例规格、网络、域名、可用区和资源数量，须由实际云环境与团队决策确认，不在此处虚构。

## 2. B组部署逻辑

### 2.1 逻辑区域与组件职责

| 区域 | 候选组件 | 职责 | 边界与安全要求 |
|---|---|---|---|
| 外部数据区 | OpenAlex、DBLP等获准公开来源及标注模拟数据 | 提供论文等公开数据；其他成果按批准来源接入 | 遵守来源条款、限速和停止机制；保留来源与采集时间 |
| 访问接入区 | Web前端、管理前端、HTTPS入口 | 用户查询、登录、认领；管理员审核和任务管理 | 浏览器不直连数据库、对象存储或搜索集群 |
| 应用计算区 | ECS/CCE承载的应用服务 | 认证、检索、门户/认领、统计、管理后台 | 服务按职责隔离；管理接口强制鉴权和审计 |
| 异步计算区 | 采集Worker、ETL Worker、任务调度组件 | 采集、清洗、去重、消歧、增量处理和索引更新 | 任务可停止、可恢复、幂等；队列/调度产品待选型 |
| 关系数据区 | RDS | 账号、学者/机构/成果元数据、认领授权、任务状态和审计元数据 | 权威业务状态；数据库凭据仅服务端持有 |
| 对象数据区 | OBS | 原始批次、导入文件、可追溯处理产物和受控附件 | 私有桶、最小权限；认领证明不公开、不写入普通日志 |
| 检索数据区 | CSS | 面向公开范围的成果/学者检索索引 | 可从权威数据重建；索引延迟/不可用需显式处理 |
| 工程运维区 | CodeArts、日志/监控能力 | 代码托管、检查、构建、测试、制品、部署和运行观测 | 真实流水线与监控未执行前不得标记为已配置 |

### 2.2 主要数据流

1. 用户浏览器通过 HTTPS 访问前端；前端仅调用应用 API。
2. API入口将请求转发至认证、检索、门户/认领、统计和管理服务。
3. 采集任务从获准来源读取数据，将原始批次及来源元数据保存至 OBS，并记录任务/批次状态。
4. ETL Worker读取原始批次，执行清洗、标准化、去重和消歧；处理结果及权威业务元数据写入 RDS。
5. 已确认可公开的数据以可重放方式更新 CSS；CSS不是认领授权或私有证明的事实来源。
6. 检索服务查询 CSS，并遵守公开范围；需要权威详情时回查业务服务/RDS。
7. 认领申请、审核、授权与审计以 RDS 中的业务事务为准；受控证明通过授权路径读取 OBS，不进入公开索引。
8. 统计服务只对定义清楚的数据范围和版本计算，结果应能说明统计口径与更新时间。
9. CodeArts将通过质量门禁的固定版本制品部署至测试/演示环境；生产/最终演示环境部署需人工审批和回滚准备。

## 3. 网络与安全边界

- 公网仅暴露 HTTPS 访问入口；RDS、OBS私有对象、CSS和内部Worker不直接向公网开放。
- 应用服务按最小权限访问所需数据资源；采集Worker仅访问获准来源和所需对象路径。
- 开发、测试/演示、最终演示环境使用独立配置和数据资源，禁止共用真实密钥。
- 密钥由环境变量或云平台密钥管理能力注入；仓库只保存变量名和脱敏示例，不保存真实密码、令牌、AK/SK、IP或个人证明材料。
- 日志记录请求ID、任务ID、批次ID、版本、错误类别和耗时；禁止记录密码、令牌、证明正文和敏感个人信息。
- 模拟数据必须在数据、页面、统计和汇报中标注，不得冒充真实采集成果。

## 4. 环境划分

| 环境 | 用途 | 数据要求 | 进入下一阶段的门槛 |
|---|---|---|---|
| 开发环境 | B组日常开发与模块联调 | 合成夹具、匿名化或获准公开样本；可重置 | 构建、静态检查和相关单元测试通过 |
| 集成测试环境 | 验证API契约、跨模块流程和数据一致性 | 固定版本测试集；与开发库/索引隔离 | 契约、接口、集成和关键异常测试通过；缺陷有记录 |
| 演示/验收环境 | 固定版本演示完整业务链路 | 经核对的演示数据；模拟数据明确标识 | 部署版本、数据manifest、冒烟结果和回滚点可追溯 |
| 生产环境（如课程要求实际部署） | 面向真实用户运行 | 仅使用授权数据与正式凭据 | 资源审批、备份恢复、权限、监控、回滚均经实际验证 |

当前项目没有证明已建立上述云环境；此表为目标环境设计。

## 5. 运行保障与故障处理

| 风险场景 | 预防/检测 | 恢复动作 | 可验收证据 |
|---|---|---|---|
| 采集重复执行 | 任务ID、批次ID、来源记录、幂等键 | 从已提交检查点恢复；重复批次不重复计数 | 同一输入重跑前后规范成果数可对账 |
| ETL中途失败 | 分阶段状态、错误分类、失败记录 | 仅重试失败阶段；低置信度记录隔离复核 | 失败后恢复记录、处理前后计数和隔离样例 |
| CSS不可用/延迟 | 健康检查、索引版本、延迟指标 | 返回依赖故障而非空结果；恢复后重放/重建索引 | 故障注入记录、恢复后RDS/CSS对账 |
| RDS不可用 | 连接健康、备份、容量监控 | 停止写入并提示服务异常；按备份恢复预案处理 | 备份记录、恢复演练记录（执行后填写） |
| 认领并发/半授权 | 事务边界、版本校验、唯一约束、审计 | 失败事务回滚；仅保留一个有效授权 | 并发测试、失败注入测试、授权数据核查 |
| 越权访问/证明泄露 | 服务端鉴权、对象权限、日志脱敏 | 撤销凭据、封禁访问、审计追查 | 权限测试和日志抽查结果 |
| 错误版本部署 | 制品版本、提交SHA、部署审批 | 回退到上一稳定制品；数据库迁移单独评估回滚 | 部署记录、制品校验值、回滚演练 |
| 资源耗尽/任务积压 | CPU/内存/磁盘、连接池、任务积压和失败率 | 限流、暂停非关键任务、扩容或分批处理 | 监控截图、负载测试记录、容量记录 |

## 6. 监控与运行指标建议

建议至少观察：应用健康状态、HTTP错误率与响应时间、RDS连接数/CPU/存储、CSS健康状态与索引延迟、OBS读写失败、Worker运行数/积压数/失败数、任务耗时、批次处理量、端到端链路耗时。

具体阈值（例如P95响应时间、最大积压量、告警持续时间）必须在团队确认测试负载和课程验收口径后设定；当前不把任何候选数字写成已批准指标。
