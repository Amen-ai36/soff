## 事实边界

项目任务书要求基于华为云 CodeArts 完成软件工程流程，架构部署图应涉及 ECS/CCE、RDS、OBS、CSS。当前仓库尚未冻结技术栈、实际云资源、CodeArts 项目配置、构建命令、测试命令、制品格式和环境地址。因此本包交付的是**可评审的方案设计和质量门禁**，不是已经部署、已经跑通流水线或测试通过的证明。

本方案沿用统一 SRS 的业务边界：公开/模拟数据采集，清洗去重消歧，权威数据存储，公开检索，门户认领与审核，统计分析。不得在本岗位材料中改变公共 API、业务实体、状态枚举或验收标准；变更需成员1、6共同确认。
