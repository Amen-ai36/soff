# GitHub 提交说明

## 1. 解压后上传什么

压缩包顶层是 docs/，路径从 docs/contributions/member-08/ 开始。将这个 member-08 文件夹放到现有 soff 仓库的 docs/contributions/ 中即可；不要把外层压缩包名当作仓库文件夹嵌套一层。现有 member-01、member-06 和统一交付目录无需覆盖。

本包只有新增贡献文档、图及合成夹具，不含原任务书、原仓库副本、构建脚本、真实人员材料或 .git。上传 ZIP 本身不便评审，建议解压后上传目录内文件。

## 2. 网页提交步骤

1. 打开已有 GitHub 项目，确认是团队指定仓库。
2. 查看分支：如果团队要求先交 B 组个人贡献，选 b；如果要求通过公共文档 PR 提交，则从当前公共文档分支创建个人文档分支。不要误选 a。
3. 在仓库根目录选择 Add file → Upload files，将解压后的 docs 文件夹拖入；确认预览路径是 docs/contributions/member-08/…。
4. 提交前核对仅新增 member-08 目录；建议通过新分支和 Pull Request 交给组长，不直接修改公共基线。
5. 填写以下标题/说明并提交。请由成员 3 复核，成员 1、6 决定正式归并。当前统一阶段入口在 main，旧分工中的 shared-baseline 仅为建议，不自行要求团队增加该分支。

没有替你创建远程仓库、上传文件、发通知或建立 PR；这里只提供你自行提交所需材料。
